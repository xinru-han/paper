# Q2 — 表6（M2机制：工资/消费/存款/流动储蓄）存款缺失率约47%：核实原因 + 恢复尝试

**更正说明**：用户提供的原始 `revision/` 管线代码（`scripts/06_analysis.R`、`07_mechanisms.R`、
`08_income_build.py` 等）确认——**表6 = M2 机制表**（工资/消费/存款/流动储蓄稳健性检验，来自
`07_mechanisms.R`），而不是先前误当作表6的"2013-2020工资子样本"稳健性检验（那是修改方案中要求
**追加到表6的一列**："已有，加2013–20工资子样本列"）。已按原始代码在 R 管线重新生成完整表6
（`tab6_M2_precaution.md`），本诊断相应更新。

## 一、缺失率复核

`hb13` = **本年末家庭银行存款总额[元]**，用于表6的 asinh(存款) 与 asinh(流动储蓄) 两列
（`07_mechanisms.R` 中限定 `year<=2020`，因 2021 年后该问项从问卷中移除）。

| 统计口径 | 缺失率 | 说明 |
|---|---|---|
| `year<2023`（基准估计窗口，原始模型dta） | **47.1%** | 修改方案 Limitations 段引用的"~47%"对应这一口径 |
| `year<=2020`（表6存款列使用的窗口，原始hb13） | 37.1% | |
| 表6回归最终估计样本（lncovid+全控制变量完整案例，year<=2020） | 23.9% | 经过控制变量完整案例过滤后进一步降低 |

三者差异的原因：47.1% 把 **2021–2023 三年 100% 缺失**计入分母（这三年不进入表6存款回归，
但属于基准估计窗口 year<2023）；37.1%/23.9% 是仅在实际用到 hb13 的 year<=2020 回归样本内计算。

## 二、原因（在原始 农户数据.dta 中核实，非样本选择造成）

原始 `农户数据.dta`（12 分析县，全部农户）中 `HB13` 逐年缺失率：

| 年份 | HB13缺失% | HG13(利息,流量代理)缺失% |
|---|---|---|
| 2013 | 38.2% | 61.7% |
| 2014 | 37.5% | 64.0% |
| 2015 | 39.4% | 64.9% |
| 2016 | 39.6% | 71.9% |
| 2017 | 41.2% | 70.8% |
| 2018 | 34.4% | 73.1% |
| 2019 | 35.1% | 68.3% |
| 2020 | 22.9% | 54.1% |
| **2021** | **100%** | 7.0% |
| **2022** | **100%** | 9.1% |
| **2023** | **100%** | 10.8% |

**两点结论（原始数据层面核实，非清洗或样本选择引入）：**

1. **2021–2023 年 100% 缺失是结构性的。** `HB13`（年末存款余额）在 2020 年后被移出入户问卷——
   2021/2022/2023 三年**全部农户**（不止分析子样本）该项均为空，与工资变量的问卷断点同源
   （`08_income_build.py` 的 `wage_old`/`wage_new` 分段构造正是应对这同一次问卷改版）。
2. **2013–2020 年 23–41% 缺失是普通的项目无应答。** 存款余额属敏感财务信息，历来拒答率偏高。

## 三、能否在原始数据中解决？

- **存款余额本身（HB13）无法恢复**：2021+ 从未采集，任何来源都无法补齐。
- **表6 已按原设计将存款/流动储蓄两列限定在 `year<=2020`**（避开 100% 缺失的 2021–23），这正是
  原始 `07_mechanisms.R` 采取的处理方式——不是缺陷，而是设计选择，本次已在 R 管线精确复现
  （见下）。
- **可选的处理期流量代理 `HG13`=银行存款利息收入**：2021–2023 缺失率仅 7–11%，可作稳健性佐证
  （口径为流量而非存量，不能直接替换）。

## 四、表6 — R 管线精确复现结果

| 列 | Log(Covid) 系数 | N | 与文档目标对照 |
|---|---|---|---|
| asinh(工资收入)（自建，逐年，含2021-22问卷断点） | **-0.2646\*\*\*** (0.0977) | 11,258 | 精确一致（文档：-0.265\*\*\*） |
| ln(消费支出)（部分口径，不含燃料/自产食物） | -0.0224 (ns) | 14,090 | 精确一致（文档：≈0） |

**关键修正**：先前复现使用了错误的工资构造（误用 `aworkincomecpi` 处理 2021-22），全样本工资系数
为 -0.2343（非精确）。获得原始 `08_income_build.py` 后确认正确构造为：2013-2020 年加总
`hg02_1..hg11_1`（分行业打工收入），2021-2022 年改用四个新问卷项（本地从业工资性收入、外出从业
工资性收入、乡村干部乡村教师工资收入、其他工资性收入）之和，CPI 平减后拼接。按此重建，
**全样本工资系数精确复现为 -0.2646\*\*\*, N=11,258**，与文档完全一致。

## 五、对表6注的建议改写

> 表6 存款/流动储蓄两列限定 `year<=2020`（2021年后该问项从入户问卷中移除，全样本一致的结构性
> 删除）；即使在此窗口内，存款缺失率仍达 23.9%–37.1%（视是否叠加控制变量完整案例过滤），加总
> 至基准估计窗口(year<2023，含100%缺失的2021-23三年)后为约47%。存款余额在2021年后不可恢复；
> 若需处理期的储蓄行为佐证，可参考持续采集的"银行存款利息收入"（HG13，2021–2023缺失率<11%）。
