# 推荐组合：家庭差异，还是函数形式差异

## 主线与贡献

核心问题：中国家庭食品需求差异，有多少在共同价格预算条件和更宽函数形式下仍保留？

**建议 A 为经济主线，B 为结论检验，不把两套方法平行堆成文章。** 家庭结构为主要比较，区域为外部情境；先审计可比性与推断，再搜索预定差异的可行反例。

拟实现的贡献：

1. 区分现实购买构成差异与共同条件下的家庭需求响应差异。
2. 对同一差异分别量化抽样不确定性与函数形式依赖，识别可被拟合不差函数推翻的经验排序。
3. 提供可复核函数、差异统计量和敏感性证据，使限制与结论的关系透明。

这些是待实现目标，不是已取得结果。需求系统、聚类推断和敏感性方法均有既有来源；不把“中国样本大”“分组多”或“使用 LLM”单独列为创新。

## 英文论文结构

| 部分 | 组织方式 |
| --- | --- |
| Introduction | 经济动机、文献缺口、具体问题、设计与贡献；执行后再概括结果 |
| Related literature | 食品需求异质性、标准化与聚合、函数形式对结论的影响 |
| Data and design | 八分类、家庭定义、24 省价格、支持与参考分布 |
| Demand estimation and inference | 联合模型、参与与条件购买、差异检验、少聚类和多重比较 |
| Household demand differences | 实际构成、共同条件、差异区间与量级，区域为次分析 |
| Functional-form dependence | 目标、工作模型、宽函数类、拟合约束、反例与验证 |
| Discussion and conclusion | 哪些排序可支持、哪些依赖限制；集中讨论识别边界 |

不再以“有涨有跌所以篮子成本不同”作主要贡献。原成本抵消可作价格背景或附录；原弹性保留为基准，不让新旧主题争夺主线。

## 不同结果意味着什么

| 结果 | 可写结论 | 不能写 |
| --- | --- | --- |
| 差异显著，且找到反向可行函数 | 参数化差异存在，但排序依赖函数形式 | p 小即说明异质性稳健 |
| 差异显著，有限搜索无反例 | 预定检查内保持一致，列明范围 | 所有合理函数都支持 |
| 差异不显著，敏感性又大 | 精度和限制不足以支持精细排序 | 家庭完全相同 |
| 支持不足或有效省份少 | 当前资料不支持该对比，缩小问题 | 扩大户月数即可解决 |
| 标准化后差异减弱 | 现实分布是重要背景 | 完全识别了偏好或结构的因果作用 |

## 实施顺序

1. 作者确认主比较、模型层和试点目标。
2. 复现基准，审计分组、有效省份和支持，不选择性报显著结果。
3. 完成 A 的联合估计、差异检验与主图；若比较不可行，先缩小问题。
4. 完成 B 的解析诊断与两个目标试点，独立验证函数。
5. 决定是否扩展，保留目标、失败和版本记录。
6. 有新结果后重写英文稿，引言按常规学术结构组织。

能否独立投稿取决于经济发现、识别和敏感性的信息量，不由检验数量或新工作流预先保证。
