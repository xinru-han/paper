# NBER 工作流：适配与验收

## 方法来源与分工

作者的[输入模板](https://github.com/JMSLab/DirectedSensitivity/blob/main/workflow/TEMPLATE.md)、[执行流程](https://github.com/JMSLab/DirectedSensitivity/blob/main/workflow/WORKFLOW.md)和[报告格式](https://github.com/JMSLab/DirectedSensitivity/blob/main/workflow/REPORT.md)将目标、函数类、工作模型和拟合准则具体化。本项目采用这种审计结构，不直接把保险需求示例当食品系统运行。

LLM 协助推导、基函数设计、编程和审计；数值来自实际执行与独立复核。数学主张保留推导，可选形式化验证不是试点必要条件。

## 阶段与门槛

| 阶段 | 工作 | 通过标准 | 不通过时 |
| --- | --- | --- | --- |
| 基点 | 核对版本、参数、目标、准则与样本 | 原目标和拟合值可复现，散列可追踪 | 不进入搜索 |
| 解析 | 检查有定义、嵌套、无界性，尝试降维或解析界 | 推导及适用条件明确 | 若无界，先修订目标或限制 |
| 基函数 | 构造包含基准的有限子空间 | 零扰动还原基准，导数匹配中心差分 | 修正表示与导数 |
| 可行搜索 | 上下方向搜索，保存路径 | 报告节点满足拟合及函数约束 | 不纳入不可行节点 |
| 独立复核 | 从保存参数重算目标、准则及限制 | 不依赖成功标记，全作用域验证 | 标为无效证据并留日志 |
| 抽样层 | 如需要，对省级扰动重复完整优化并论证推断 | 区分抽样误差和有限优化误差 | 试点只报样本内敏感性 |

解析步骤若已解出问题，不必再强行数值搜索。若只得到解析反例，与数值结果分别记录。

## 计算试点

两个待审目标，各向下、向上搜索；三个基函数子空间，每个方向每个子空间最多五个起点，总计最多 60 条路径。每条路径上限 5,000 次准则调用与 5,000 次目标调用，缓存、可行化与独立验证调用另有明细。预算耗尽保留已验证节点，不解释为收敛。

起点含精确基准及其附近经可行化的扰动，不以随机不可行点作为证据。保存种子、容差、停止原因和最优已找到可行值。以上是待审计算上限，不是已运行次数。

试点有实质信息再扩展。若只有极端曲线才反转，展示曲线，并在另一层预定平滑限制下单独重做；不删除反例，或无版本地事后改变“合理”的定义。

## 建议运行目录

```text
heterogeneity_sensitivity_run/
  code/                  Stata/Mata 与独立验证
  logs/                  版本、种子、命令及失败原因
  design/                经作者确认的目标、分组与支持规则
  outputs/heterogeneity/ 联合估计、直接差异、乘子与多重调整
  outputs/sensitivity/   可行函数、路径及有限价格响应
  checks/                导数、嵌套、矩压缩与约束验证
  review/                汇总图表和证据说明
```

这是未来建议结构，本轮未生成估计输出。原始交易、家庭标识、户级预测与轨迹不进入公开网站或 GitHub。

## 敏感性证据字段

| 字段组 | 内容 |
| --- | --- |
| 基点 | model_id、目标公式版本、样本/参考权重/参数散列、Q0、c0 |
| 候选 | basis_id、参数文件、方向、种子、Q、c、拟合余量 |
| 约束 | 正预测、加总、齐次、导数界、作用域、验证方法、最大违反量 |
| 计算 | 调用数、用时、停止原因、可行节点、失败类别 |
| 解释 | 反例与否、敏感性下界、解析或全局保证与否 |

保存 `certificates.json` 和 CSV。解析界不存在时填 `null`，不填 0，不用局部搜索冒充全局界。

## 与 Stata 衔接

保留指定目录的数据和价格处理。固定第一阶段的 SY 试点可用 Mata 封装条件拟合与导数；如调用 Python 求解器，只传必要的无标识数值对象，再由 Stata 交叉核对。不因作者包使用 Python 就更换清洗、价格或食品分类。

exact 扩展须检验：新增项后的矩压缩是否精确；成本函数需求导数是否匹配数值解；工作模型与候选是否使用同一支持和工具。按候选参数定义的价指数或隐含效用，应每次正确更新，不能为省计算而冻结。

## 分开报告的不确定性

- 工具、分类与价格构造变化：识别或测量敏感性。
- 样本变化：构成与外推敏感性。
- 第一阶段固定搜索：仅覆盖第二阶段。
- 省级抽样误差：区间与少聚类诊断。
- 约束 exact：边界推断适用性。
