## B. 计量硬伤（跑通之后仍必须改，否则过不了审稿）

### B1. 混合价格的 fold 泄漏（违反自设 No-Go）

`30` 中 `int_cat <- fold_cells[n_hh >= 30, .(int_lp = mean(int_lp)), by = ...]` 把 **5 个 fold 排除估计取平均**——家庭 i（在 fold k）只在第 k 个估计中被排除，在其余 4 个中被包含，平均后 ≈ 全样本中位数。随后 `lp_hybrid` 由这个 fold 均值构造并**不带 fold 维度**地 merge 进面板。结果：只要用 `lp_hybrid` 跑稳健性规格（`make_wide(panel, price_col = "lp_hybrid")`），家庭自身单位价值就重新进入了自己需求方程的价格——这正是方案 Go/No-Go 里写明的 LOO 泄漏红线。主规格（`lp_ext` 纯外部）不受影响，但混合规格是价格三角验证的必要一环，不能带病使用。

**修复**：保留 fold 维度——`int_group` 按 `(fold, Province, year_month, food_group10)` 聚合（fold_cells 本来就有 fold 列，是 `int_cat` 那一步把它平均掉的）；`hyb` 相应带 fold；panel merge 键加 `fold`。认证表可以继续用 fold 平均版（认证不要求自我排除），但**进入需求方程的价格必须是 fold 专属的**。

### B2. 两步不确定性没有任何传播渠道

`system_cluster_vcov` 与 `wild_cluster` 都把 Φ̂、φ̂（第一阶段生成回归元）、FGLS 的 Σ̂、Stone 权重当作已知常数。后果：σ_g 的标准误无效（经典 Murphy–Topel 问题），所有含价格系数的 SE 系统性低估；A(z) 的 Wald 检验（`az_wald_test_v2.csv`）建立在同一个 naive vcov 上。代码注释承诺"full two-step uncertainty is carried by the pairs cluster bootstrap"，31_lib 也为此设计了频数权重接口——**但 bootstrap 脚本不存在**。承诺了没实现，等于没有。

**修复**：补写 `33_pairs_bootstrap_v2.R`：按家庭成对聚类重抽样（用 31_lib 的 `wt` 频数权重通道，家庭级计数权重，无需复制行）→ 每轮重估 probit + FGLS 系统 + 弹性 → B=200。主表全部区间来自它；解析 SE 保留为参考列并在表注标明 two-step-naive。在 bootstrap 到位前，任何弹性都不能配"显著性"表述。

### B3. "wild cluster bootstrap" 名不副实且未学生化

`wild_cluster()` 实际是**未学生化的 score/multiplier bootstrap**：对省级 score 块乘 Webb 权重、经 `xtx_inv` 映射成系数扰动，p 值 = `mean(|draw| ≥ |β̂|)`。三个问题：其一，这不是 Cameron–Gelbach–Miller 意义上的 WCR（无零约束残差、无重估）；其二，未学生化——24 个规模高度悬殊的省簇（广东/江苏 vs 小省）下，未学生化版本的检验尺寸可能明显失真，而 wild bootstrap 的理论优势恰恰来自学生化统计量的渐近精细化；其三，论文若写 "wild cluster bootstrap (Webb weights)"，熟悉这套方法的审稿人会核对实现。

**修复（择一）**：(i) 学生化：每个 draw 用该 draw 的省级 score 重算 meat → draw 专属 SE → 比较 t 统计量分布（score 结构下每轮只是 24×P 的 rowsum 重加权，成本极低）；(ii) 对价格系数逐个做零约束的标准 WCR-t；(iii) 保留现实现但如实改名为 "score-based cluster multiplier bootstrap" 并引用相应文献。另外：`system_cluster_vcov` 无小样本修正——省级聚类至少乘 CR1 因子 G/(G−1)（24 簇时约 +2% SE，家庭聚类可忽略）。

### B4. "QUAIDS" 是错误标签

`quaids = TRUE` 唯一的变化是把价格交互的乘子从 y 换成 y²（`ym <- if (quaids) y_easi2 else y_easi`）。这不是 Banks–Blundell–Lewbel 的 QUAIDS（没有 λ 项与 b(p) 结构、Engel 曲线设定完全不同），而是"y² 价格交互的 EASI 变体"。作为函数形式敏感性完全合法，但任何表格、文件名、正文用 QUAIDS 一词都会被打回。**修复**：全局改名（如 `easi_y2p`），或按真 QUAIDS 另行实现。v1 的同名问题一并处理。

## C. 中度问题（应改或必须在论文中披露）

**C1. 价格–份额覆盖不匹配。** 组价格只覆盖 `observed_external` 子篮：乳制品价格 = 常温奶+鲜奶+奶粉（缺酸奶、奶酪、黄油——而酸奶两类在交易量上恰是乳制品大头）；主食缺挂面。预算份额却是全组支出。这是可辩护的近似（子篮代理组价），但必须：报告每组"被定价子篮占该组支出的比例"（一行代码：2021 年 observed 类支出/组总支出）；对覆盖率低的组（预计乳制品最低）做"份额收窄到被定价类别"的稳健性；在数据节明确披露。否则酸奶与牛奶价格走势分化时会造成系统性的相对价格误测。

**C2. 认证的 level 相关是 pooled 截面。** `corr_level = cor(lp_int, lp_ext)` 混合了跨省水平差与时间变异，可能靠截面一致性"虚高通过"，而 FE 结构下识别靠的恰是时间变异。`corr_delta` 部分弥补，但建议加一列**同省内时间序列相关的中位数**（按省 demean 后再算），作为第三项认证指标。

**C3. `predict_shares` 的截断+再归一仍在，且现在位于弹性数值导数的路径内。** 已保存 `resid_share_range`（好）；跑通后必须检查该分布——若 G03 残差份额出现负值或再归一幅度可感知，需在文中说明加总仅对潜在份额按构造成立；边界截断处的导数扭结在子组弹性（小样本子组）中风险更高。

**C4. OOF 交叉验证有三处轻微不洁**：`sw_k` 算了但 `predict_shares` 根本不使用（死参数——y_easi 与 r 列始终是全样本 Stone 权重派生）；训练折沿用全样本 Σ；probit 用全样本 warm start（这个无害）。数值影响极小，但要么修掉（predict 前用训练折权重重新 derive），要么在文中注明 OOF 是"给定全样本平减指数下的份额方程折外拟合"。

**C5. A(z) 推断链**：Wald 用家庭聚类 naive vcov；价格交互项的相关变异在省级，应同时报告省聚类与（修好 B3 后的）bootstrap 版本；最终显著性以 B2 的 bootstrap 为准，且按上轮方案做多重检验校正。

**C6. 纯外部价格的测量误差方向要讨论。** 主规格换纯外部价后，外部监测价对家庭实际面对零售价的经典测量误差会导致弹性衰减（偏向 0）——这与 v1 的 UV 污染方向不同。修好 B1 的混合规格 + M3 纯内部规格正好构成三角：三口径弹性同向且量级接近，就是对测量误差不敏感的最强证据。文中要有这段论证。

**C7. 弹性现在包含参与边际（probit 随价格扰动重算）——这是对 v1 的实质改进，值得在方法节明确写出**；同时说明 Mundlak 均值在扰动中固定的口径（短期响应、家庭长期成分不变）。
