# EASI_V2 计量经济学审计与 AJAE / Food Policy 投稿前修改清单

## 一、审计范围与总体判断

### 1. 审计范围

本次审计基于 `EASI_V2.zip` 中的以下内容：

- 价格指数与家庭—月—品类面板构建代码；
- Shonkwiler–Yen 两阶段零消费处理；
- EASI 需求系统、CRE/Mundlak 处理、FGLS 估计；
- 家庭和省级聚类标准误、score multiplier bootstrap；
- 家庭成对 bootstrap；
- 曲率约束、正则性、遗漏方程不变性、样本外拟合；
- 频率、截尾、零消费、价格口径等稳健性；
- 补偿变差（CV）福利测算；
- 已生成的主要结果、诊断表和运行日志。

由于压缩包中未包含 `data_derived`、外部价格原始文件、完整运行入口和软件环境锁定文件，本次能够完成的是**代码与结果的一致性审计、识别与推断逻辑审计、结果诊断审计**，不能完全替代从原始数据开始的独立复现。

### 2. 总体结论

当前版本已经明显超过一般需求系统论文的基础配置，优点包括：

- 使用省—月外部价格而非家庭单位价值作为主价格；
- 采用九类食品完整份额系统并严格满足加总约束；
- 对零购买采用 Shonkwiler–Yen 两阶段处理；
- 加入 CRE/Mundlak 项；
- 同时报告家庭和省级聚类推断；
- 开展家庭层面两阶段 bootstrap；
- 检查曲率、遗漏方程不变性和样本外拟合；
- 对购买频率、极端值和价格来源进行了多项稳健性分析。

但以 **AJAE** 或 **Food Policy** 的严格标准衡量，当前版本仍不宜直接作为最终投稿模型。至少存在四项可能改变核心结论的高风险问题：

1. **EASI 实际支出及其非线性项没有处理内生性，当前 FGLS 不能保证一致性。**
2. **价格识别发生在省—月层面，但主要弹性区间依赖家庭层面重抽样，存在严重的有效样本量和小聚类推断问题。**
3. **曲率约束仅约束潜在 EASI 系统，却没有保证含购买参与概率的无条件需求可积；当前 Hicksian 弹性与福利 CV 的理论基础不足。**
4. **月度零值主要是“未购买”而不一定是“未消费”，购买周期变量的排除限制很强，且现有频率和双重门槛稳健性中存在不可用结果或代码问题。**

因此，建议将修改分为：

- **A 类：投稿前必须修正；**
- **B 类：强烈建议补充；**
- **C 类：增强说服力与可复现性。**

# 二、A 类：投稿前必须修正的问题

## A1. EASI 实际支出内生性尚未处理

### 现有做法

`src/31_lib_v2.R:66–89` 中，实际支出定义为：

\[
y_{it}=\ln x_{it}-\sum_j \bar w_{j,pt}\ln p_{j,pt},
\]

其中 \(\bar w_{j,pt}\) 是省—月平均预算份额。随后在份额方程中直接使用：

- \(y_{it}\)；
- \(y_{it}^2\)；
- \(y_{it}\times r_{j,pt}\)。

`src/32_estimate_main_v2.R:54–57` 直接以 FGLS 估计系统，没有 IV、3SLS、GMM 或控制函数步骤。

### 主要问题

#### （1）总食品支出通常是内生变量

总食品支出与未观测偏好、家庭临时冲击、记录误差和份额方程误差可能相关。即使本文是条件食品需求系统，也不能自动假定总食品支出外生。

如果 \(y\) 内生，则以下变量均内生：

\[
y,\qquad y^2,\qquad y r_j .
\]

仅对误差协方差进行 FGLS 处理不能解决该问题。

#### （2）当前所谓“固定权重 Stone deflator”并非真正固定

`compute_stone_weights()` 在 `src/31_lib_v2.R:66–75` 中使用**每个省—月当期家庭平均预算份额**作为权重。该权重随时间变化，并由本期消费选择生成，因此：

- 它是生成变量；
- 它可能与份额方程误差相关；
- 它会使 \(y\) 的内生性更加明显；
- 代码注释中的“fixed-weight Stone deflator”与实际实现不一致。

需要区分：

- 外部品类价格指数确实使用 2021 年固定品类权重；
- EASI 实际支出中的 Stone 权重却是省—月当期平均份额，不是固定权重。

#### （3）Mundlak 的 `mean_y_hh` 也继承内生性

`src/31_lib_v2.R:94–99` 用家庭样本期平均 \(y\) 构造 `mean_y_hh`。若 \(y\) 内生，该家庭均值不能自动视为外生控制变量。

### 必须补做的工作

#### 方案 A：以非线性 3SLS / 系统 GMM 作为主估计

建议将以下变量列为内生变量：

\[
y,\quad y^2,\quad y r_1,\ldots,y r_8,
\]

如果保留 EASI-y2p 规格，还包括：

\[
y^2r_1,\ldots,y^2r_8.
\]

可使用：

- 非线性 3SLS；
- iterated 3SLS；
- 系统 GMM；
- 控制函数与系统估计相结合。

Lewbel–Pendakur 的 EASI 原始框架本身允许并强调使用非线性 IV/3SLS/GMM，而不是将实际支出直接作为外生变量处理。

#### 工具变量设计

应优先寻找有明确经济含义的排除变量。可考虑但必须逐项论证：

1. 家庭收入档及其非线性项；
2. 非食品支出或家庭总预算；
3. 家庭收入、工资或就业冲击；
4. 滞后收入或滞后预测支出；
5. 由人口结构、收入和外生地区变量预测的食品支出；
6. 价格与上述支出工具的交互项，用于工具化 \(yr_j\)；
7. 预样本家庭平均支出，而不是全样本同期均值。

注意：收入只有在条件可分离、且不直接影响品类偏好的结构假设下才可作为排除工具，不能仅因其与支出相关就自动视为有效。

#### 至少报告以下诊断

- 各内生变量第一阶段或条件第一阶段；
- partial \(R^2\)；
- Kleibergen–Paap 或相应系统弱识别统计量；
- Sanderson–Windmeijer 条件强度检验；
- Hansen \(J\) 或差分 Hansen/C-statistic；
- 支出外生性的 Durbin–Wu–Hausman或控制函数残差检验；
- 弱工具稳健的 Anderson–Rubin / CLR 型区间，至少针对主要自身价格弹性或核心参数；
- OLS/FGLS 与 IV/3SLS 结果的并列表。

### 最低可接受标准

AJAE 投稿前，主表不能仅保留当前 FGLS 结果。至少需要：

- 一套可辩护工具变量；
- 系统 IV/3SLS/GMM 估计；
- 工具强度和有效性诊断；
- 主要自身价格弹性在 FGLS 与 IV 之间的稳定性比较。

## A2. 推断层级与价格变化层级不匹配

### 现有事实

价格是 24 个省、36 个月、9 个品类的省—月变量。每个省—月中的大量家庭共享同一价格。

现有推断包括：

- 家庭聚类 CR1；
- 省级聚类 CR1；
- 24 省的 score multiplier bootstrap；
- 家庭 pairs bootstrap，并用其构造主要弹性置信区间。

### 主要问题

#### （1）价格系数的有效独立变化不来自 58 万个家庭—月观测

价格识别主要来自省—月变化。将家庭作为 bootstrap 单位会保留几乎相同的价格路径，却把家庭数量当作不确定性的主要来源，容易显著低估价格弹性的标准误。

当前 bootstrap 区间非常窄，与只有 24 个价格聚类的识别结构并不相称。

#### （2）24 个省属于小聚类问题

普通 CR1 在 24 个且规模高度不均衡的聚类下可能存在明显尺寸扭曲。当前 score multiplier bootstrap：

- 不是在零假设下重新估计的 restricted wild cluster bootstrap；
- 没有完整重新估计第一阶段和所有生成变量；
- 主要用于价格参数，而非最终弹性和福利；
- 使用 `mean()` 计算 bootstrap p 值，可能得到 0，未使用 \((1+\#)/(B+1)\) 修正。

#### （3）还可能存在全国月份共同冲击与省内时间相关

同一月份的全国性供需冲击可能使不同省份误差相关；同一省份的误差也可能跨月序列相关。

### 必须补做的工作

#### 主推断

对价格参数、弹性和福利结果采用以下至少两种方法：

1. **省级 CR2 + Satterthwaite 自由度修正；**
2. **restricted wild cluster bootstrap**，优先 WCR-S、WCR-V 或 jackknife-based 版本；
3. **leave-one-province-out cluster jackknife；**
4. 对全部两阶段和生成变量进行省级重抽样或省级 wild bootstrap 后重新估计。

#### 双向相关稳健性

至少报告一种处理全国月份共同冲击的方法：

- 省 × 年月双向聚类；
- 省内时间 HAC，同时加入完整年月固定效应；
- 省级 block bootstrap；
- 以省—月为聚合单元的稳健性估计。

#### 弹性区间必须在正确层级生成

省级重抽样中应重新执行：

1. Stone/EASI 实际支出构造；
2. 第一阶段参与方程；
3. IV/3SLS/GMM 系统；
4. 弹性；
5. 曲率与福利。

家庭重抽样可以作为补充，用于家庭构成不确定性，但不能作为外部价格弹性的唯一或主要推断依据。

### 建议报告

- 家庭聚类区间；
- 省级 CR2 区间；
- restricted wild cluster bootstrap p 值/区间；
- leave-one-province-out 分布；
- 双向聚类结果。

如果不同推断方法结论差异较大，应以省级小聚类稳健结果为准。

## A3. 曲率约束、无条件弹性与福利测算不一致

### 现有结果

未约束模型的聚合 Slutsky 最大特征根为：

\[
0.0190,\qquad 95\%\,CI=[0.0014,0.0441],
\]

173 次成功 bootstrap 中曲率通过比例为 0。

曲率约束模型在潜在 EASI 代表点上可以通过，但：

- 含参与概率的无条件弹性仍在 210 次 bootstrap 中全部曲率不通过；
- 约束前后自身价格弹性变化很大，例如：
  - 主食：\(-1.079\rightarrow-2.454\)；
  - 食用油：\(-0.778\rightarrow-1.833\)；
  - 猪肉：\(-0.644\rightarrow-1.066\)。

这说明曲率约束不是无关紧要的小修正，而是会实质改变核心经济结论。

### 代码层面的原因

`impose_curvature()` 约束的是潜在份额系统中的 \(B+yC\)。

但 `compute_elasticities()` 使用：

- 价格变化对购买概率的影响；
- 价格变化对条件份额的影响；
- 份额截断与归一化；
- 聚合数量变化；

由此得到无条件 Marshallian 弹性，再通过 Slutsky 关系机械构造：

\[
E^H=E^M+\eta w'.
\]

这种含独立参与概率的两阶段需求并不一定来自同一个可积效用函数，因此：

- 生成的 “Hicksian” 矩阵不一定对称；
- 对其进行事后对称化再检查特征根不能恢复可积性；
- 潜在系统的曲率约束不能自动保证无条件系统曲率。

### 对福利分析的影响

`src/35_welfare_cv_v2.R` 使用上述无条件 “Hicksian” 弹性构造对称化 Slutsky 矩阵，并计算二阶 CV。

如果该矩阵不是一个可积需求系统的真实 Slutsky 矩阵，则：

- 二阶福利近似缺乏严格理论依据；
- 代偿效应可能被错误估计；
- 当前低收入组几乎完全被替代效应抵消的结果不宜作为政策结论。

### 必须选择一种处理路线

#### 路线 1：保留 EASI 结构福利，但把福利限定在潜在需求系统

- 使用满足理论约束的潜在 EASI 系统；
- 明确区分“潜在消费需求”与“月度购买参与”；
- 福利只基于可积的潜在需求；
- 参与概率模型只用于解释购买记录中的零值，不进入 Hicksian 福利矩阵。

需要解释为何潜在需求可代表消费，而不是购买。

#### 路线 2：改用由效用最大化推导的角点需求模型

例如：

- Kuhn–Tucker demand system；
- MDCEV；
- 可积的随机效用角点模型；
- 能同时处理角点与福利的结构模型。

该路线最严格，但计算成本最高。

#### 路线 3：删除福利作为主结果

对于 Food Policy，可以：

- 将文章定位为月度购买需求与政策异质性；
- 主文仅报告 Marshallian 购买弹性；
- 将福利 CV 删除或降为探索性附录；
- 不再将参与调整后的矩阵称为严格 Hicksian 弹性。

如果目标是 AJAE 且福利是核心贡献，则不能绕开可积性问题。

### 必须新增的正则性检验

1. 无条件 “Hicksian” 矩阵非对称程度：
   \[
   \|S-S'\|,\quad \max_{ij}|S_{ij}-S_{ji}|.
   \]
2. 未对称化矩阵与对称化矩阵的结果差异；
3. 各家庭—月预测份额非负率；
4. 每个品类被截断的观测比例与截断幅度；
5. 单调性、加总、齐次性、对称性和曲率的完整表；
6. 理论限制的 Wald/距离检验，而不是只施加限制；
7. 约束与非约束模型的拟合损失和弹性变化；
8. 福利结果在潜在系统与无条件系统之间的比较。

## A4. 零购买、购买频率和排除限制仍不充分

### 1. 月度零值的经济含义

央视扫描数据记录的是购买而非真实食用。对主食、食用油、奶制品等可储存品：

- 当月零购买不代表零消费；
- 当月低购买可能是上月囤货；
- 月度价格弹性更接近“购买时点弹性”，不一定是“消费需求弹性”。

论文必须在标题、摘要、模型和政策解释中明确区分：

- purchase demand；
- consumption demand。

当前模型若继续使用月度数据，建议称为**家庭食品购买需求系统**。

### 2. 购买周期变量的排除限制很强

第一阶段使用：

- 上月是否购买；
- 距离上次购买的时间；
- 无历史购买记录。

这些变量被排除在份额方程之外。

但对于可储存商品，过去购买会通过库存直接影响本月购买数量或份额。因此它们不仅影响“是否购买”，也很可能影响“购买多少”，排除限制并不显然成立。

### 必须补做的排除限制检验

1. 将购买周期变量加入第二阶段份额方程，做联合显著性检验；
2. 对可储存品与易腐品分别检验；
3. 使用不同滞后长度；
4. 加入未来一期购买变量作为 placebo lead；
5. 删除购买周期排除变量重新估计；
6. 仅保留最有理论依据的排除变量；
7. 报告第一阶段增量拟合和第二阶段敏感性；
8. 讨论库存、囤货与促销时点机制。

若购买周期变量在份额方程中显著，不能继续作为严格排除工具使用。

### 3. 双重门槛稳健性存在前视分类

`src/40_freq_winsor_zero_v2.R:139–174` 用家庭在完整 2020—2022 样本期是否曾购买某类商品定义 `ever_buyer`。

这使用了未来信息，会造成：

- look-ahead bias；
- 以内生结果定义结构性零；
- 将样本期短或暂时未购买者错误识别为结构性零。

应改为：

- 使用独立预样本期识别；
- 使用样本初期固定窗口；
- 使用 latent class / finite mixture；
- 或完全删除该稳健性。

此外，该规格在系统估计中手工把第一门槛乘入 `Phi`，但弹性计算时 `predict_shares()` 又重新调用原 probit，并未持续保留第一门槛，因此现有 Z1 弹性不一定真正对应所估计的双重门槛模型。

### 4. 28 日频率结果存在代码错误

`src/42_fourweek_frequency_v2.R:67–75` 仅对原始交易中出现的家庭—28日—品类组合聚合，没有构造完整的：

\[
ID\times 28日窗口\times 9品类
\]

零值网格。

因此 `spend>0` 几乎恒成立，输出购买率约为 0.9997—0.99996。该结果无效，必须删除并重跑。

正确做法：

1. 先构造每个家庭在观察期内的完整 28 日窗口；
2. 与 9 个品类笛卡尔展开；
3. 合并购买金额；
4. 未匹配者置零；
5. 再计算购买率和两阶段需求。

### 5. 季度和年度完整 SY 系统不可用

`src/40_freq_winsor_zero_v2.R` 强行在季度和年度频率运行完整参与系统，结果出现：

- probit pseudo-\(R^2\) 为 NA；
- 多数品类季度自身价格弹性机械等于 \(-0.990099\)；
- 多数年度弹性机械等于 \(-1.016338\)；
- 最大特征根异常大。

`src/41_frequency_benchmark_v2.R` 已正确指出年度参与率趋近 1，SY probit 退化，完整系统不被识别。因此：

- 删除 `F1_quarterly` 和 `F2_annual` 的完整系统结果；
- 保留并改进 reduced-form 购买率与 intensive-margin 分解；
- 季度模型只有在仍存在足够零值并重新设计参与方程时才可使用。

### 推荐的稳健性框架

主文可报告：

1. 月度无条件购买弹性；
2. 月度 extensive / intensive margin 分解；
3. 正确构造的 28 日窗口；
4. 季度 among-purchaser intensive elasticity；
5. 易腐品与可储存品分组；
6. 删除购买周期变量后的结果。

## A5. 遗漏方程/计价品不变性没有通过

### 现有结果

将蔬菜 G03 作为遗漏方程与将猪肉 G05 作为遗漏方程相比：

- Marshallian 弹性最大绝对差：0.4217；
- 支出弹性最大差：0.0319；
- 两组 Marshallian 弹性相关系数：0.9489。

相关系数较高不能替代不变性。0.42 的最大差对自身价格和交叉价格弹性而言较大。

### 可能原因

1. 参与方程随遗漏品重新参数化；
2. 省—月 Stone 指数和相对价格共同变化；
3. 两阶段非线性变换；
4. 遗漏份额通过残差恢复；
5. 负预测份额被截断并重新归一化；
6. 模型限制在不同遗漏方程下没有完全等价；
7. 数值 ridge 对不同参数化产生不同影响。

### 必须补做的工作

1. 估计所有 9 个份额方程并通过线性约束处理加总奇异性；
2. 或使用明确的最小距离/参数变换，使不同遗漏方程只是同一模型的等价重参数化；
3. 对 9 个可能遗漏品分别估计并报告弹性分布；
4. 取消预测阶段的事后截断后重新检查；
5. 检查齐次性、对称性及参与概率转换是否在全系统中一致；
6. 报告差异是否小于相应省级 bootstrap 标准误。

建议设定内部通过标准：

- 主要自身价格弹性在不同遗漏品下符号一致；
- 最大差显著小于一个省级 bootstrap 标准误；
- 主要政策模拟结论不随遗漏方程变化。

当前结果不能表述为“通过了 numeraire invariance”。

# 三、B 类：强烈建议补充的问题

## B1. 完整年月固定效应与价格识别

当前系统使用：

- 月份季节固定效应；
- 年固定效应；

而不是 36 个完整年月固定效应。

这无法吸收：

- 2020 年疫情不同月份的全国冲击；
- 全国食品供给、运输和宏观政策冲击；
- 特定年月的全国需求变化。

建议主规格加入：

\[
\text{Province FE/CRE}+\text{YearMonth FE}.
\]

进一步稳健性可加入：

- 省份线性趋势；
- 区域 × 年月固定效应；
- 省 × 年固定效应；
- 疫情阶段 × 地区；
- leave-one-province-out。

价格方差分解显示，在省固定效应、月份固定效应和年份固定效应后，不少品类仅剩 5%—13% 左右的原始价格变异。加入完整年月效应后应重新报告：

- 残余价格标准差；
- 最小和最大值；
- 有效省—月单元数；
- 各品类识别贡献；
- weak variation / leverage 诊断。

## B2. 外部价格仍可能内生，价格测量误差较明显

使用外部市场价格明显优于家庭单位价值，但“外部”不等于“外生”。

本地价格可能同时受本地需求冲击影响。尤其猪肉、水果、蔬菜和鲜活产品，省级需求变化可能反馈到市场价格。

### 建议

1. 说明外部价格的具体来源、采集规则、覆盖市场和处理过程；
2. 使用供应侧价格工具变量：
   - 主产区天气冲击 × 省份基期采购暴露；
   - 全国批发价格冲击 × 省份基期消费权重；
   - 运输、燃料或进口成本冲击；
   - 滞后供给冲击；
3. 避免直接把本地温度等可能影响消费的变量当作价格工具；
4. 对价格内生性做控制函数或 IV 检验；
5. 报告 price-IV 第一阶段和弱工具稳健结果。

### 价格覆盖问题

2021 年外部价格覆盖的组内支出比例：

- 主食约 90.1%；
- 乳制品约 62.2%。

乳制品价格主要代表常温/鲜奶和奶粉，未充分覆盖酸奶、奶酪、黄油等。需补做：

- 仅保留已定价子品类的需求系统；
- 不同乳制品篮子权重；
- CPI 分项或其他零售价格替代；
- 价格测量误差敏感性；
- SIMEX 或 reliability-ratio 式校正（若能够估计可靠度）；
- 删除乳制品后的八品类系统。

当前内部—外部价格认证中，食用油和乳制品相关性较弱，蔬菜、水果、牛羊肉、海鲜缺少可用内部信号。认证结果应如实作为限制，不宜仅以“纯外部价格”概括为已完全解决价格质量问题。

## B3. A(z) 检验强烈拒绝同质价格反应

A(z) 价格异质性交互项的检验结果：

- 家庭聚类 Wald：\(p<10^{-48}\)；
- 省级 score sup-t：\(p\approx0.001\)。

这意味着当前同质价格系数主模型存在明显函数形式遗漏。

但脚本注释称最终显著性应依靠 pairs bootstrap，而现有 `34_bootstrap_v2.R` 并未对 A(z) 规格实施完整 bootstrap。因此当前 A(z) 推断还不完整。

### 建议

1. 将 A(z) 或一个更简洁的异质性结构提升为主规格；
2. 仅保留事前有理论依据的交互项；
3. 对交互项使用省级 restricted wild bootstrap；
4. 直接检验组间弹性差，而不是比较两个置信区间是否重叠；
5. 对多组、多品类差异使用 simultaneous confidence bands 或 FDR；
6. 对低收入、老年、大家庭的弹性差报告联合检验。

如果为控制参数量而保留同质主模型，应明确说明 A(z) 拒绝结果，并把同质模型定位为平均近似，而不能将其视为已充分设定的结构模型。

## B4. Engel 曲线阶数与 EASI rank 需要正式选择

当前只有 \(y\) 和 \(y^2\)，相当于较低阶的 Engel 曲线。EASI 的优势之一正是允许更高 rank 或样条。

建议估计：

- 线性；
- 二次；
- 三次；
- 四次；
- 五次；
- restricted cubic spline。

选择依据：

1. 内生性处理后的联合显著性；
2. BIC/AIC 或 GMM criterion；
3. household-fold out-of-sample fit；
4. 弹性稳定性；
5. 支出支持区间内的单调性和曲率；
6. 高阶项的弱识别诊断。

不应仅以 EASI-y2p 作为唯一函数形式稳健性。代码已明确其不是 QUAIDS，但输出中仍存在 `*_quaids_v2.csv`，必须清理旧结果，避免误报。

---

## B5. CRE/Mundlak 处理需要正式检验

当前 Mundlak 项包括：

- 家庭平均 \(y\)；
- 家庭平均相对价格。

建议补充：

1. Mundlak 项联合显著性检验；
2. CRE 与不加 CRE 的比较；
3. 家庭固定效应或 within-transformation 稳健性；
4. first-difference 规格；
5. pre-sample mean 规格；
6. 家庭随机斜率或 correlated random coefficients 的可行性分析。

需要注意，家庭平均价格可能主要反映家庭所在省份和观察期构成，而不是家庭层面的内生异质性；家庭平均 \(y\) 又存在前述内生性。

---

## B6. 理论限制应“检验后施加”

当前对称性等限制主要被直接参数化施加。高水平期刊通常希望看到：

- 加总；
- 齐次性；
- Slutsky 对称性；
- 单调性；
- 曲率；

分别是否被数据拒绝。

建议：

1. 先估计可识别的较少约束模型；
2. 对齐次性和对称性做 Wald/距离检验；
3. 再报告理论约束模型；
4. 比较拟合、弹性和福利；
5. 对曲率使用不等式约束下合适的推断，不宜简单套用普通 percentile bootstrap。

---

## B7. 预测份额截断与有限差分可能扭曲弹性

`predict_shares()` 将所有小于 \(10^{-8}\) 的预测份额截断后再归一化。

现有遗漏蔬菜份额的原始预测分布中：

- 最小值约 \(-0.306\)；
- 0.5% 分位数约 \(-0.038\)。

因此负预测并非单纯机器精度误差。

### 风险

- 隐藏单调性/非负性失败；
- 使目标函数和弹性映射非光滑；
- 价格扰动前后可能跨越截断点；
- 自身价格和交叉价格弹性依赖有限差分步长；
- 事后归一化改变理论导数。

### 必须补充

1. 每个品类负预测比例；
2. 截断前后平均绝对变化；
3. 任一品类被截断的家庭—月比例；
4. \(h=0.001,0.005,0.01,0.02\) 的步长敏感性；
5. 改用中央差分：
   \[
   \frac{q(p+h)-q(p-h)}{2h};
   \]
6. 尽可能推导解析弹性；
7. 采用在估计阶段保证份额非负的参数化或约束；
8. 不允许只在预测阶段“修正”不合法份额。

---

## B8. 样本外拟合较弱，需要更完整的模型诊断

五折样本外 \(R^2\) 多数约为 0.02—0.10，蔬菜为负值。这不必然否定结构模型，但说明预测份额的能力有限。

建议补充：

- 每个品类 observed vs predicted calibration plot；
- 购买概率 decile calibration；
- Brier score 和 AUC 的样本外版本；
- 份额 RMSE/MAE；
- 省份、年份、收入组的预测误差；
- 残差自相关；
- 残差与价格、支出、预测概率的关系；
- 高杠杆省—月单元；
- leave-one-province-out 弹性；
- influential cluster diagnostics。

不能仅报告平均样本外 \(R^2\)，还要解释结构模型为何在拟合较弱时仍可用于弹性和福利。

---

## B9. bootstrap 需要重做

### 当前问题

- 默认仅 200 次；
- 当前非约束版本只有 173 次成功；
- 旧日志曾仅 100/200 成功；
- 主 `Sigma` 在每次复制中固定；
- 因而并非真正“full pipeline re-estimation”；
- constrained estimator 位于约束边界，普通 percentile bootstrap 未必有效；
- 失败复制直接删除，未检查失败是否随机。

### 建议

1. 主结果至少 999 次，最好 1999 次；
2. 每次重新估计残差协方差 `Sigma`；
3. 保存每次：
   - 收敛状态；
   - ridge 大小；
   - 条件数；
   - 第一阶段状态；
   - 弹性合法性；
4. 对失败复制分析其样本构成和参数特征；
5. 不接受低于 95% 的成功率；
6. 同时报告 percentile、basic 和 bootstrap-t；
7. constrained/boundary 问题考虑：
   - subsampling；
   - m-out-of-n bootstrap；
   - projection inference；
   - 或只把约束模型作为 regularity sensitivity；
8. 省级重抽样优先于家庭重抽样；
9. p 值使用：
   \[
   p=\frac{1+\sum 1(T_b\ge T_0)}{B+1}.
   \]

# 四、C 类：增强严谨性和投稿竞争力的工作

## C1. 面板选择、缺失月份与记录强度

主面板仅保留总食品支出大于 0 的家庭—月。需要区分：

- 家庭确实没有购买九类食品；
- 家庭该月没有被完整记录；

建议形成：

3. 平衡面板与非平衡面板比较；
4. 零总食品支出月份的数量；
5. 记录交易数与家庭特征的关系；
6. inverse probability weighting；
7. 仅保留连续观察家庭；
8. 不同最小有效月数样本；
9. 疫情期间记录中断诊断。

当前 `minTx3/5/8` 是有用起点，但不能替代系统性的面板选择分析。

## C2. 样本权重与外部有效性

代码中所有家庭权重均为 1。若央视面板不是严格概率抽样，则全国平均弹性和福利不能自动代表全国人口。

建议：

- 将样本的省份、收入、家庭规模、年龄结构与人口统计资料对比；
- 构造 post-stratification / raking 权重；
- 报告加权与未加权结果；
- 福利全国汇总使用人口或家庭代表权重，而非样本家庭数；
- 说明样本覆盖的是城市、农村还是混合家庭；

## C3. 九品类条件系统与坚果排除

坚果平均约占十类食品支出的 3.26%。删除坚果后，系统估计的是条件于九类食品的需求。

需要：

1. 明确支出弹性是条件食品支出弹性，不是收入弹性；
2. 解释品类外支出变化；
3. 尝试：
   - 加入坚果的替代价格；
   - 将坚果并入相近品类；
   - 将坚果设为 outside good；
   - incomplete demand system；
4. 报告删除坚果前后家庭总食品支出构成；
5. 检验坚果份额是否与收入和价格显著相关。

## C4. 人口规模与等价尺度

家庭规模由区间中点代替，且另有近似 OECD 等价尺度。建议：

- 原始家庭规模组；
- 中点人均；
- OECD 等价尺度；
- 不做规模调整；
- 老年/儿童家庭不同等价尺度；

分别估计主要弹性。若等价尺度是生成变量，bootstrap 中也应重新处理或至少报告敏感性。

## C5. ridge、条件数和数值稳定性

`fit_system()` 会自动在 \(X'X\) 和 \(\Sigma\) 上逐级增加 ridge，但输出中未报告最终 ridge。

需要保存：

- 每次估计所用 ridge；
- \(X'X\) 条件数；
- \(\Sigma\) 最小特征根；
- 参数对 ridge 的敏感性；
- 是否存在近似共线性；
- 不同尺度标准化后的结果。

如果不同复制采用不同且较大的 ridge，当前估计已带有未披露的正则化偏误。

## C6. 多重检验和同时置信区间

81 个价格弹性、多组异质性和多项稳健性会产生大量显著性检验。

建议：

- 自身价格弹性联合检验；
- 交叉价格弹性联合检验；
- sup-t simultaneous bands；
- Romano–Wolf stepdown；
- Benjamini–Hochberg FDR；
- 组间差异的联合检验；
- 明确区分事前假设与探索性结果。

不建议逐个强调交叉弹性的 5% 显著性。

# 六、建议的最终计量模型框架

## 方案一：AJAE 导向的严格结构版本

### 第一阶段：购买参与

对每个品类：

\[
d_{igt}^{*}
=
Z_{igt}'\gamma_g
+\alpha_{ig}
+\tau_t
+u_{igt},
\qquad
d_{igt}=1(d_{igt}^{*}>0).
\]

要求：

- CRE 或相关随机效应；
- 完整年月固定效应；
- 有效的参与排除变量；
- 省级小聚类稳健推断；
- 考虑多品类参与相关性；
- 购买周期变量通过排除检验。

### 第二阶段：IV-EASI

\[
w_{igt}
=
\Phi_{igt}
\left[
a_g(z)
+\sum_{r=1}^{R}b_{gr}y_{it}^{r}
+\sum_j A_{gj}(z)\ln p_{jt}
+\sum_j C_{gj}y_{it}\ln p_{jt}
\right]
+\delta_g\phi_{igt}
+\varepsilon_{igt}.
\]

其中：

- \(y,y^2,yr_j\) 使用 IV；
- 主规格采用系统 GMM/3SLS；
- 完整年月固定效应；
- CRE/FE；
- 对称性、齐次性和曲率正式检验；
- 价格按省级小聚类推断；
- A(z) 异质性至少部分进入主规格。

### 福利

只有在无条件系统可积，或福利明确基于潜在可积系统时才报告。

---

## 方案二：Food Policy 导向的稳健购买需求版本

如果现有数据难以支持完整结构福利模型，可采取更稳妥的定位：

1. 明确研究对象是食品购买而非实际消费；
2. 主模型为 IV-EASI 月度购买系统；
3. 零购买分解为：
   - extensive purchase margin；
   - intensive purchase margin；
4. 主结果报告 Marshallian 购买弹性；
5. 不把无条件 Slutsky 矩阵称为严格 Hicksian；
6. 删除或弱化福利 CV；
7. 加强政策冲击、低收入家庭和可储存品异质性；
8. 使用省级小聚类稳健推断；
9. 将购买频率和库存机制作为核心解释。

该版本在理论负担上低于 AJAE 结构版本，但仍必须解决支出内生性、推断层级和错误频率稳健性。

# 八、建议的执行顺序

## 第一阶段：先做会改变结论的修改

1. 修正 28 日、季度/年度和双重门槛代码；
2. 清理陈旧输出与目录；
3. 用完整年月固定效应重估；
4. 设计并估计 IV-EASI；
5. 重做省级小聚类推断；
6. 验证购买周期变量的排除限制；
7. 重新判断 A(z) 是否应作为主模型。

在完成以上步骤前，不建议继续精修福利或写最终政策结论。

## 第二阶段：处理理论一致性

1. 检查无条件 Hicksian 对称性；
2. 检查 clipping；
3. 改用中央差分或解析导数；
4. 修复遗漏方程不变性；
5. 决定福利采用潜在系统、角点结构模型，还是删除。

## 第三阶段：增强稳健性

1. Engel rank/spline；
2. 价格工具和价格覆盖；
3. 家庭 FE/CRE；
4. 面板选择/IPW；
5. 样本校准权重；
6. 多重检验；
7. 999—1999 次有效 bootstrap。

# 九、投稿前 Go / No-Go 标准

只有满足以下条件后，建议进入 AJAE 投稿稿件定稿：

- [ ] \(y,y^2,yr_j\) 已进行有效 IV/3SLS/GMM 处理；
- [ ] 工具变量强度和有效性通过或得到透明解释；
- [ ] 价格弹性使用省级小聚类稳健区间；
- [ ] 省级 bootstrap 成功率不低于 95%，有效复制不少于 999；
- [ ] 完整年月固定效应下核心弹性稳定；
- [ ] 购买周期排除限制未被明显拒绝；
- [ ] 28 日频率结果基于完整零值网格；
- [ ] 不再使用退化季度/年度 SY 结果；
- [ ] 不再使用全样本 `ever_buyer` 定义结构零；
- [ ] 主要结果不对遗漏方程高度敏感；
- [ ] 预测份额非负性和截断比例透明；
- [ ] constrained 与 unconstrained 差异得到解释；
- [ ] Hicksian/福利具有明确可积性基础；
- [ ] A(z) 强拒绝结果得到模型层面的回应；
- [ ] 价格覆盖与测量误差稳健性完成；
- [ ] 代码可从原始/派生数据一键复现。

对于 Food Policy，福利和全局曲率可以不作为核心贡献，但以下仍属于最低要求：

- [ ] 支出内生性得到处理；
- [ ] 推断层级正确；
- [ ] 月度结果明确解释为购买需求；
- [ ] 零购买与购买频率处理有效；
- [ ] 无效稳健性结果已删除；
- [ ] 政策异质性结论使用正式组间检验。

## 最终判断

该版本已经具备较强的模型开发基础，但目前最核心的风险不是“少做了几个稳健性检验”，而是**结构识别、推断层级和福利可积性尚未完全闭合**。

建议首先完成：

1. IV-EASI；
2. 省级小聚类全流程推断；
3. 零购买与排除限制重构；
4. 无条件曲率/Hicksian/福利重新定位；
5. 遗漏方程不变性修复。

完成这五项后，再决定：

- 走 AJAE 的严格结构需求与福利路线；
- 或走 Food Policy 的月度购买弹性、异质性与政策含义路线。
