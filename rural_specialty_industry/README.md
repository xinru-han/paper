# 乡村特色产业论文组合（rural_specialty_industry）

三篇论文的方案、代码与结果。数据底座：`/root/data/数据/乡村产业数据/` 等（本地，不入库）。

## 三篇实证已完成（2026-07，各 paperN/RESULTS.md 为结果备忘）

- **common/** 行政区划编码底座（淘宝村五级代码全集：41,541镇/3,004县）+ 地名匹配器 `admin_match.py`
- **paper3/** 亿元村/十亿元镇——政策培育vs追认：离散时间logit。**强镇几率比≈13倍、政策叠加剂量反应单调递增、时序65%培育**。
- **paper1/** 产业强镇交错DID：Sun-Abraham事件研究。**灯光朴素+17%、镇特定趋势稳健+5.5%**、事件研究诚实处理选择性、认定无增量效应。
- **paper2/** 认证叠加：县×品类事件研究。**边际回报递减甚至转负（牌子化内卷）**，仅首块GI有正效应，注册资本随层数恶化。

每篇 code/（Python建面板 + R计量）、output/（结果表txt+系数csv+png图）、RESULTS.md。

## 工商注册数据（2010–2023，逐年处理中）

原始：`/root/data/数据/乡村产业数据/工商注册数据/YYYY.dta.zip`（14年，解压后每年约18GB）。
字段含成立日期、注册地址、**经纬度**、三级行业、注册资本、企业类型（含农民专业合作社）。
处理策略：逐年解压→聚合→**删除解压.dta（保留zip）**，避免占满磁盘。
地区口径用 省份/城市/区县（地址/信用代码，可靠）；经纬度/县代码为名称地理编码产物(~1.5%错配)，仅在涉农企业级子集保留供后续空间校验。
全量核对（14年）：共约2.15亿家企业；涉农占比8.4%→14.1%（2010→2022）；农民专业合作社占比2013见顶2.4%后降至2023年0.4%（吻合合作社空壳清理周期，效度信号）。⚠️2023为部分年/登记滞后，涉农与合作社数偏低，分析时注意截断。
最终面板（`output/`）：`agri_total_county_year.csv`（2,967县×14年，涉农企业数/资本/合作社数）、`agri_county3_panel_2010_2023.csv`（县×三级行业42类×年，挂接品种用）；全行业面板233MB本地保留不入库；逐年大文件与企业级pkl本地保留（见 `.gitignore`）。
