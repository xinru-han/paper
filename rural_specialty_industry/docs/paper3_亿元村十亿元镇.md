# Paper 3（中文顶刊，最快成稿）：从亿元村到十亿元镇——乡村特色产业"超级明星"的政策培育还是政策追认？

**目标期刊**: 《中国农村经济》/《管理世界》
**英文缩减版**: China Agricultural Economic Review / China Economic Review

---

## 1. 研究问题

亿元村（693个）/十亿元镇（466个）是乡村产业的极端成功案例（superstar）。官方政策话语强调"梯度培育"：一村一品→产业强镇→现代产业园（县）→优势特色产业集群（省）。核心问题：

**先期政策认定（GI/一村一品/强镇/产业园/特优区）是否因果地提高了亿元村、十亿元镇的涌现概率，还是政策在追认既有赢家？**

直接回应"锦上添花 vs 雪中送炭"之争，并检验"梯度培育"政策设计是否真实起作用（例：所在县先有产业园/特优区，是否显著提高镇内亿元村出现率）。

## 2. 数据（基本齐备，外部需求最少）

- 结果：亿元村/十亿元镇名单，2020/2021/2022 三期进入（`亿元村和十亿元镇.xlsx`，含省/市县/乡镇/村四级地名）。
- 解释变量（全部取2020年前的存量与时点）：
  - GI（2008–2019 按省—产品，县域提取后到县）
  - 一村一品示范村镇（9批，村镇级——**与亿元村同层级，最直接的"培育"变量**）
  - 产业强镇批准建设（2018/2019 两批）
  - 现代产业园创建/认定（2017–2019）
  - 特优区（2017–2019 三批）
- 自建省级面板（`数据.xlsx`）中的认定率 = 认定/创建，直接用于政治经济学一节。

## 3. 实证设计

### 3.1 离散时间风险模型（主）
以镇（村）为单元、2020–2022为风险期：

```
Pr(Enter_it) = Λ(β₁·Policy_i,pre2020 + β₂·CountyPolicy_c,pre2020 + α_county + γ_category + X)
```

- 县固定效应 + 产品类别固定效应；梯度培育检验 = β₂（县级产业园/特优区对镇内超级明星涌现的溢出）。
- 时序检验（培育 vs 追认的核心判别）：
  - **培育**：政策认定显著早于亿元村进入，且认定—进入间隔与政策强度相关；
  - **追认**：进入名单前1年内政策认定概率跳升（reverse timing），或政策认定集中在已进入者。
  - 用双向时序事件研究呈现：以亿元村进入年为0点，画前后各政策认定的hazard。

### 3.2 认定时点DID（辅）
对2018/2019批产业强镇建设镇 vs 2021+批建设镇（尚未处理），比较2020–2022十亿元镇进入率——与Paper 1设计A共用管线的简化版。

### 3.3 政治经济学一节（副产品，已有数据直接可做）
省际认定率（认定/创建）差异的解释：粮食主产区倾斜、脱贫县倾斜、名额分配惯性。自建面板已算好认定率，补省级协变量即可。

## 4. 结果结构

1. 描述性事实：超级明星的空间分布（东部沿海集中度、省际基尼）、品类分布、与政策认定的重叠率矩阵
2. 主表：各层级政策对进入概率的边际效应（村级一村一品 vs 镇级强镇 vs 县级园区）
3. 时序判别图：培育 vs 追认
4. 梯度检验：政策层级组合（只有村级 / 村+镇 / 村+镇+县）的进入率阶梯
5. 交叉验证：夜间灯光/企业注册验证亿元村名单的测度性质
6. 政治经济学：认定率的省际决定因素

## 5. 测度诚实性（审稿人必问）

亿元村/十亿元镇名单是**遴选而非普查**——它是"官方确认的超级明星"，存在申报与确认环节。处理：
- 明确其测度性质，解读为"被官方认定为超级明星"的概率；
- 用夜间灯光、企业注册数交叉验证名单镇村确实系统性更强；
- 稳健性：若官方确认本身受政策认定影响（同一系统偏好），用灯光定义的"影子超级明星"（灯光前1%镇）重跑主表。
