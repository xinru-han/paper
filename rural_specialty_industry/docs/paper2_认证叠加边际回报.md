# Paper 2（英文，方法与问题双新）：一品多牌——农产品认证"叠加"的边际回报

**英文题目（暂定）**: Certification Stacking: The Marginal Returns to Layered Agri-Food Quality Labels in China

**目标期刊**: Food Policy / AJAE / European Review of Agricultural Economics

---

## 1. 研究问题与贡献

GI（地理标志）研究已经拥挤，但本数据的独特之处在于**同时拥有完整的品牌政策栈**：同一"县×产品"可能先后叠加——

1. 农产品地理标志 AGI（2008–2022，3,510个，产品级）
2. 全国名特优新目录（5,605条，县区级+生产企业名单）
3. 中国农业品牌目录（2019/2020–21/2022–23三期，约550个）
4. 特色农产品优势区（4批308个，县级+产品）
5. 一村一品示范村镇（9批，村镇级）
6. 优势特色产业集群覆盖（224个，省级+产业）
7. 产业强镇主导品种（第二批认定257个含品种）

**核心问题：第 k 块"牌子"的边际效应是多少？** 是政策互补（1+1>2），还是"牌子化"内卷下的边际递减、甚至纯粹寻租信号？据检索无人定量回答过。

对话文献：
- 质量认证与出口/价格：Macchiavello & Miquel-Florensa (2019, coffee)；Bold et al.；GI溢价文献（Mérel; Deselnicu et al. 2013 meta）
- 新产业政策评估：Juhász, Lane & Rodrik (2024)；政策叠加对应"policy mix"讨论
- 中国农业品牌政策：中文文献多为定性/截面，缺乏事件研究证据

## 2. 数据构建：县×产品面板

### 2.1 单元定义
- 单元 = 县 × 产品类别（HS-4或农业部品类）；年度 2008–2023。
- **GI县域提取**：AGI数据只有省份字段，县域需从产品名称（多数含地名前缀，如"五常大米"）和证书持有人名称（如"XX县XX协会"）中解析。规则匹配 + 民政部地名库 + 尾部10%人工校验。名特优新自带县区字段，可作交叉校验锚。
- 处理事件 = 每一次新增认定（policy, batch_year），形成每个单元的认证序列 {t₁<t₂<…<t_k}。

### 2.2 结果变量
| 变量 | 来源 | 说明 |
|---|---|---|
| 认证企业池：企业数/注册资本 | 名特优新生产企业名单（证书编号内嵌年份）→ 工商数据扩展 | **杀手锏**：打开"牌子→企业进入→产业化"链条 |
| 产地品类价格效应 | **发改委城市居民食品零售价1995–2024（已在库）**：GI县所在地级市×产品品类的零售价 | 次优：测认证对产地品类价格的影响，**不能**测GI产品专属溢价（价格是泛品类的） |
| GI产品专属溢价 | 电商在售价（淘宝/京东爬取，产品级可直接观察"五常大米"vs普通大米）；或农业农村部批发价（若可得） | 质量溢价（最优） |
| 县级出口单价/数量 | 海关HS-8（需渠道，可选） | 国际溢价 |
| 亿元村涌现 | 本数据，匹配到县×产品 | 产业化极端结果 |
| 电商销量/搜索热度 | 淘宝/百度指数（可选） | 需求侧 |

## 3. 识别策略

### 3.1 逐层事件研究（主设计）
对第 k 次认证事件做事件研究，样本限定为"最终拿到 ≥k 块牌子"的单元，利用**各计划批次时点的准外生错落**（同一单元第k块牌子何时到手，取决于所处计划的批次窗口，而非单元自身选择的连续时点）：

```
Y_{cpt} = Σ_e β_e^{(k)} · 1[t − T_{cp}^{(k)} = e] + α_{cp} + λ_{category×t} + ε
```

剂量—反应曲线：{β^{(1)}, β^{(2)}, β^{(3)}, …} 的比较即"边际回报曲线"。

### 3.2 内生性与工具性变异
叠牌顺序内生（好产品先拿牌、也更容易拿下一块牌）。应对：
1. **配额约束工具**：各计划有省级名额（自建面板已算认定率），同类别单元在"省内名额松/紧年份"面临不同获牌概率——用 quota-induced timing 变异；
2. 同产品类别×同批次内比较（吸收产品景气）；
3. 已有第 k−1 块牌子的单元内比较（条件于既有认证组合）；
4. 异质性核心表：**"锦上添花 vs 雪中送炭"**——按基期产业基础（基期GI早/晚、基期灯光）分组的边际效应。

### 3.3 组合效应
不只看次序，还看**组合**：GI+特优区（产品认证×区域政策）是否互补于 GI+品牌目录（两个产品认证）？用认证组合哑变量的饱和模型 + 机器学习（causal forest 按组合分裂）探索。

## 4. 预期结果结构

1. 描述：认证叠加的普遍性（多少县×产品拿到≥2/≥3块牌）、叠加时序模式
2. 第1块牌的效应（对标现有GI文献做基准校验）
3. 边际回报曲线：β^(k) 随 k 递减/递增？
4. 组合互补性矩阵
5. 机制：认证企业池扩张、价格溢价、出口
6. 政治经济学：哪些县在"集牌"？与转移支付/官员激励的相关性（副产品节）

## 5. 风险

- GI县域提取精度：预计85%+可规则匹配，剩余人工；名特优新县区字段做锚。
- 价格数据分品种覆盖不全：以企业进入为主结果，价格为辅。
- "certification stacking"概念需在引言立住：用1-2个典型案例（如某茶叶县2010 GI→2017特优区→2019品牌目录→2021集群）开场。
