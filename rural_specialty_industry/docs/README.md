## 数据家底（核验后行数）

**政策认定类**
- 产业强镇批准建设 2018–2024 七批约1,643个镇（254/298/259/298/200/200/134）；通过认定 2018–2021 批次 196/231/159/184 + "第二批认定"257个（含主导品种）。认定⊂建设（2018年194个认定中184个匹配到当年建设名单）
- 现代农业产业园：创建345（另副本353）、认定238（副本232），县级，2017–2024
- 特色农产品优势区：4批308个（2017–2020，县级+产品）
- 优势特色产业集群：224个（2020–2024，省级+产业）
- 一村一品示范村镇：9批，分省计数+名单（补充发现，可作论文2/3的低层级认证）

**认证与品牌类**
- 农产品地理标志（AGI）：3,510个（2008–2022），含登记年份/省份/证书持有人/类别/证书编号
- 全国名特优新目录：5,605条，含县区/面积/有效期/生产企业名单（唯一直接挂接企业层的数据）
- 中国农业品牌目录：2019 / 2020–21 / 2022–23 三期约550个品牌

**结果类**
- 亿元村 693个、十亿元镇 466个（2020/2021/2022 三期）
- 特色农产品产量（省级，2023）
- 自建省级面板（`数据.xlsx`：含创建/认定数与认定率）

## 共同地基（三篇共用，先做）

1. **行政区划编码匹配**：镇/县名 → 12位乡镇代码/9位县代码。底册用**淘宝村DID五级代码全集** + 灯光/人口面板的乡镇代码 + `行政区变更.xlsx` 处理历年调整（撤乡设镇、县改区）。产出 `town_code_map.csv`、`county_code_map.csv`。
2. **政策事件长表**：统一 schema（unit_id, unit_type, policy, batch_year, status∈{创建,认定,未认定}, product）。产出 `policy_events_long.csv`。
3. **GI县域字段提取**：从产品名称/证书持有人名称中解析县域归属（规则+人工校验尾部10%）。

## 需补充的外部数据

**已到位（2026-07-08，`/root/data/数据/乡村产业数据/`）**
- 乡镇夜间灯光面板 1986–2024（田一禾版，含12位乡镇代码+mean/sum等统计量，**免GIS聚合直接可用**；另附县/市/省级面板与年度tif）
- 全国淘宝村DID 2008–2024（村级，1,057万行=全国村庄×年份，含省市县镇村五级代码、成为淘宝村时间、DID哑变量；**其村/镇代码全集可兼作三篇论文的行政区划匹配底册**）
- **新增企业数量统计 1949–2023**（`1949~2023...企业数量.dta`，5GB）：**区县×行业×成立年份**的新增注册企业数，含三级行业分类。⚠️ **层级是区县不是乡镇**——对paper2/paper3是理想的企业进入结果（可筛涉农行业：农林牧渔、农副食品加工、食品制造、酒饮料茶制造等）；对paper1仅能作县级机制/稳健性，镇级企业进入仍需补充（见下）
- **乡镇人口面板 2000–2024（Landscan）**：含乡镇代码的年度人口密度+估算总人口，另有县/市/省级——paper1人口集聚结果变量+控制变量（Landscan为估算非普查，但年度连续）
- **地理标志产品清洁版CSV**（`geographical_indication_agri_products.csv`，3,510条，官方greenfood.agri.cn爬取，含AGI证书编号+ID）——比原xlsx更干净，paper2主用
- 发改委价格数据（`/root/data/数据/发改委价格数据/`）——论文2价格结果**次优替代**：品类×城市零售价，测产地城市品类价格效应，无法测GI专属溢价（见paper2 §2.2）
