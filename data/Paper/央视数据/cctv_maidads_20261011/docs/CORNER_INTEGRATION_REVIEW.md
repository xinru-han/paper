# 受限角点预测与积分精度独立复核

复核日期：2026-10-12。对象为 `corner_forecast.mata` 和 `03_corner_scenarios.do`。本复核没有修改主代理的代码，没有重新估计参数，也没有 bootstrap。32 个积分点的全体户预测保留为诊断；128/256 仅运行同一子样本，不替换全体结果。

## 1. 预算导数与单位

对每个固定潜在偏好 draw，令 `A_i` 为活动商品指示，`a=sum(alpha_i*A_i)`，`P=sum(p_i*low_i*A_i)`，`C=1-(1-r)*logistic(omega*u)`，`nu=a/(m+C*P)`。当前受限模型规定 `alpha=beta`、共同高/低端点比例、`kappa=0`。

在活动集合不变的局部区间中，效用根方程满足：

```text
F_m = nu
F_u = C' * (nu*P + (1-a)/C) - 1
du/dm = -nu/F_u
dq_i/dm = alpha_i*A_i/(a*p_i)
          + C'*(du/dm)*(P*alpha_i*A_i/(a*p_i) - low_i*A_i)
```

代码的两种 `F_u` 写法相等：`sum(alpha_i*C'*low_i/(q_i+C*low_i))-1` 代入 KKT 关系后即为上式。非活动商品的数量及局部预算导数严格为零；活动边界本身可能不可微，解析式应解释为几乎处处的预算导数，不是参与概率导数。

预算用 `m_original/scale` 求解，数量用 `scale*q_scaled` 返回，因此 `dq_original/dm_original=dq_scaled/dm_scaled`。`cr_dqdm` 不应额外乘或除 `scale`。这里的原单位是覆盖购买预算及参考价格数量等价，不是物理公斤。

独立脚本 `01_corner_derivative_review.do` 用当前八类实际参数、四种家庭、32 个偏好 draw 和32 个预算点检查了4,096个案例，包含正、零、负的假设食品预算收入斜率：

| 检查 | 最大误差 |
|---|---:|
| 预算导数与原预算单位中央差分 | 8.24e-10 |
| 收入链式响应与中央差分 | 5.31e-9 |
| 数量预算闭合 | 2.57e-15 |
| `sum(p_i*dq_i/dm)=1` | 4.44e-16 |
| 非活动商品预算导数 | 0 |
| 与既有求解器数量差 | 3.55e-15 |

本次网格没有遇到差分跨越活动边界的案例，不把有限网格测试冒称所有参数及所有边界的数学证明。

## 2. 全体户汇总

独立 `01_final_corner_review.do` 实际复核了32draw的全部22,775户、318,850个户情景，未发现无效预测。336个省份情景组及56个家庭类型情景组均覆盖完整；户权重、购买参与概率均值、商品支出份额及链式导数汇总均核对通过。

数量及预算导数先对潜在偏好积分，再汇总真实家庭。收入弹性使用 `sum(cr_dqdm*m_new*eta_budget_income_new)/sum(cr_q)`，没有对零数量计算个体 `0/0`，也没有删除零购买家庭。若某汇总商品数量严格为零，其弹性保留缺失。

省份内价格统一，数量弹性与支出份额满足同价预算导数 adding-up。家庭类型跨省价格不同，商品值份额仍闭合，但数量弹性不必与这些值份额共同满足 `sum(share*eta)=1`；本次最大差约0.002152，来自价格异质性，不是预算遗漏。家庭商品支出弹性若另行计算，需使用 `sum(p_h*dq_h*m_h)/sum(p_h*q_h)`，不能与数量弹性混称。

`cr_pi` 是条件于预算、价格与家庭类型的模型参与概率。参数来自季度购买参与模型，使用年度月均预算/年度价格锚点并未估计库存或记录窗口机制，故它不能直接称“一年内至少购买一次的概率”。

## 4. 结果资格与复现

这些结果全部保持 `full_sample_fit=0`、`qualified_forecast=0`，属于 `alpha=beta`、共同端点比例的受限角点试估。全体户预测成功不等于已经在全体数据拟合，也不等于完整自由端点MAIDADS估计成功。没有生成不存在的p值、置信区间或bootstrap结论。

复核脚本为 `01_corner_derivative_review.do`、`01_final_corner_review.do`、`01_corner_integration_summary.do`。补充128/256直接调用既有 `03_corner_scenarios.do 128 sensitivity` 和 `256 sensitivity`，各使用独立 `STATATMP`；两次实际运行约2.43秒和3.91秒。

完整未舍入汇总在 `outputs/data_audit/corner_integration_summary.csv`；基线数量、增长指数、增长处收入弹性另有同前缀的独立宽表。`corner_integration_step_summary.csv` 给出各点数、两情景的相邻误差。全体32draw逐户结果和64/128/256同子样本结果均保留本地，含户标识文件不应上传公开仓库。
