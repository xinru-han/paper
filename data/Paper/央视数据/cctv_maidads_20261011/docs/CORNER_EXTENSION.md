# 央视微观零购买：受限 MAIDADS 型角点扩展

## 定位

本目录分开保存两种工作。`synthetic_validation.csv` 与 `restricted_8_all_255_sets_validation.csv` 是合成数据的算法验证，不能解释为央视估计结果。其余以 `fit`、`estimated`、`response` 命名的文件只有在实际央视户季数据估计成功后才生成。

这不是原文的完整自由端点 MAIDADS，也不是此前农户调查的“相关参与模型加消费集合归一化”。它是一个允许零购买、由效用最大化内生决定消费集合的受限隐式随机效用扩展。没有加入小常数、把交易数量零当购买零、删除某类别零购买户，或用 Cholesky 修改价格弹性。也不宣称该角点机制为已证明的首次创新。

## 效用、约束与全局规则性

候选隐式效用是

```text
F(q,u) = sum_i phi_i(u,epsilon) log[q_i + a_i(u,type)] - u - kappa = 0
phi_i(u) = alpha_i [1-s(u)] + beta_i s(u)
a_i(u,type) = exp(eta_type) low_i [1-s(omega u) + r s(omega u)]
q_i >= 0, sum_i p_i q_i = m; s(x)=1/[1+exp(-x)].
```

这里 `a_i>0` 相当于原文最低消费项的负值（signed commitment），不再解释为正最低消费量。原文 MAIDADS 通过随效用变化的最低消费项增加灵活性，但其通常定义域要求数量高于最低消费量；本文角点域从零开始，因此必须说明解释变化。[Preckel、Cranfield 与 Hertel 原文](https://web.ics.purdue.edu/~hertel/data/uploads/publications/maidads.pdf)

自由 `alpha != beta` 并不自动保证所有消费束的 `F_u<0`。本次实际微观 pilot 因而取 `alpha=beta`、`low_i>0`、`0<r<1`、固定 `omega=.7`、`kappa=0`，并允许四类家庭有不同正平移倍率。每个偏好 draw 都有正、加总为 1 的 alpha。由此得到：

```text
a'_i(u) <= 0
F_u = sum_i alpha_i a'_i(u)/(q_i+a_i(u)) - 1 < -1
F_qi = alpha_i/(q_i+a_i(u)) > 0
F_qq is negative definite.
```

因此任意非负有限消费束有唯一效用根，效用单调增加，各固定效用的上水平集凸。严格凹的固定效用对数问题与预算约束保证 KKT 解是全局需求最优解。补偿需求的 Slutsky 对称与负半定来自这一可积效用，而非估计后修正价格弹性。角点处可能不可微，必须报告有限响应的扰动宽度。

这项限制舍弃了低、高效用边际份额的独立自由变化；非齐次仍来自随效用变化的平移端点。因此它是“globally regular restricted MAIDADS-type corner pilot”，不能替代另一目录里的完整分组 MAIDADS 基准。

固定效用的可加对数结构还限制了补偿替代关系：同一内部活动集合内的跨类别 Hicksian 导数非负，只有一个类别活动时补偿自价格导数为零。随机积分可平滑活动集合切换，但不会凭空解除这一函数形式限制。不能把负自价格或正交叉价格本身当作数据单独证实的结论；必须同时查看实际拟合和留出预测。

共同高低端比率还意味着各平移可写为 `a_i=low_i*C(u)`、`C'<0`。结合固定 alpha，可以推出每个 draw 的食品预算增长使各活动商品数量非减，活动集合只会扩张；因此总食品预算响应非负，自价格 Marshallian 响应也非正。这是限制模型内建的正常品形状，不能当成由数据检验出“所有食品是正常品”。家庭收入响应仍取决于另一个预算阶段；条件正购买者均量可以因新进入低量购买者而下降，并不与总体响应非负矛盾。

## KKT 与预算闭合

给定效用，活动集合由阈值条件内生决定：

```text
nu = sum_{i in A} phi_i / [m + sum_{i in A} p_i a_i]
q_i = max[phi_i/(nu p_i) - a_i, 0]
i in A iff phi_i/(p_i a_i) > nu.
```

程序由全部类别开始剔除不满足阈值的类别，再联合求解 `F=0`。它没有用实际购买集合决定预算归一化。集合外数量严格为零，仍然进入类别参与矩。固定效用的 Hicksian 求解按阈值排序枚举嵌套活动集合，求支出最小化；价格变化时每个随机偏好 draw 保持其自己的基期效用。

允许多类别角点的随机效用有成熟文献，当前工作是在隐式效用与平移端点的特定组合中作受限扩展，不等同于原始 MDCEV 的完全自由替代。[Bhat 的 MDCEV 原始方法](https://www.caee.utexas.edu/prof/bhat/abstracts/mdcev_bhat_final_version_25sept07.pdf)

## 合成验证：已实际运行

- 两、三类系统 216 个价格与预算组合：效用根、KKT、预算、支出恢复、齐次、补偿对称及 Slutsky 曲率通过。
- 自由 alpha/beta 的合成例子只验证了给定有限域，不能外推全局规则性。
- 受限八类系统逐一构造并复现全部 255 个非空购买集合，数量恢复误差最大 `1.32e-13`，预算误差最大 `2.78e-16`，对称误差最大 `5.50e-9`，Slutsky 最大特征值 `5.55e-12`，属于数值零。
- 1024 个固定偏好积分 draw 自然形成严格大于零、低于 1 的零购买概率。此结果为模拟验证，不是央视的购买率。

日志由 Stata 17 SE 实际执行生成。若重新运行，必须设置本任务独立的 `STATATMP`，避免并行 Stata 批次临时文件相互覆盖。

## 央视 pilot 的估计设计

输入为 `household_quarter_8.csv`。主样本仅保留三个自然月均有交易记录、八类覆盖预算严格为正的户季；八类预算为零的 nut-only 户季仍保留在数据整理阶段，但条件八类预算模型无法估计其分配，单独披露排除数。原始交易 `Volume=0` 不参与零购买定义；购买由该类别金额是否为正确定。数量只用 `q=m*w/p` 的价格指数购买量等价单位，不能称公斤。

本次 pilot 按预定口径保留完整窗口，使用末记录人口代理和收入/家庭属性，**不是稳定人口主估计，也不是因果估计**。完整正预算窗口 185908 个，其中家庭、收入档、人口档的月末属性变化分别为 2177、10302、3442 个；同月交易内冲突对应为 2343、10509、3457 个。严格排除各类变化/冲突的完整稳定样本为 171612 个，另保存而不为获得某个弹性符号择删。本 pilot 尚未在稳定子样本重新估计；不稳定人口窗口按末记录人口除整个窗口金额的偏差必须保留在局限中。

2020—2021年训练，2022年留出。按省份、家庭类型和收入档，预设每层两个预算排序支持点作确定性微观 pilot；每点仍是真实户季，不是修改出的消费量，权重为该层完整户季数除以支持点数。该设计压缩计算用预算与价格分布，不能称全微观样本的完整估计，稀疏层和高端尾部必须列为局限。

实际符合上述口径的母体为训练 117537、2022年留出 68371 个户季；支持点为训练 960、留出 954 个，留出评价只能称支持点留出评价。已另外运行每层 1/2/4/8 支持点的输入矩敏感性，而非重新估计模型：两点加权训练预算均值 192.22、母体 220.95，留出 194.41、母体 223.75，均低约 13%；八点对应 211.92、214.51。两点的某些类别参与率也与母体相差 2 至 3 个百分点。不能将这个近似说成完全保留原始微观预算分布；`support_moment_sensitivity_no_refit.csv` 保存全部对照。

训练母体来自 19419 个不同家庭、192 个不同省份季度价格组合；留出来自 20747 个家庭、96 个价格组合。14646 个家庭在两个时段均出现，故这是时间留出，不是独立新家庭留出，更不能把各户季当作独立的价格冲击。`independent_variation_scope.csv` 保存这些原始变异层级计数；未来抽样推断至少要处理家庭重复观察和省份共同价格变异。

训练共 20 个自由参数：7 个共同边际份额、8 个正低端平移、共同高低端比率、偏好离散程度、3 个家庭类型倍率。目标矩同时匹配无条件预算份额与正购买概率，并使用预算、相对价格和家庭类型工具矩；不是只拟合正购买户。偏好由组成型随机份额诱导相关购买集合，不称完全自由的相关协方差系统。

使用 Stata/Mata 模拟最小距离和两个预设起点。偏好离散程度预设为 `0.05<sigma<4`，防止极端 softmax 浮点下溢；如触及边界须披露。优化采用 16 个固定 Halton 正态积分 draw，拟合检查与局部矩 Jacobian 用 256 draw；弹性曲线用 16384 draw。积分不是 bootstrap。有限积分与支持点压缩造成的误差通过提高 draw 数和留出拟合检查披露。若优化未收敛或 Jacobian 弱识别，则明确标为未达到可发表估计标准，而不把过程结束当收敛。

优化目标对非有限参数、无效需求、预算不闭合或非有限预测返回有限大罚值，不让 NaN 进入 Nelder--Mead。所有自写求解循环有明确上限；Halton 整数展开也限制最多 64 位。专用受限求解器与通用求解器在 320 个基准例子的数量差最大 `2.00e-14`。每个改善候选和每个起点结束均输出参数 checkpoint；起点一限制 900 秒，起点二限制 600 秒，各至多 1200 次目标评估。触发上限后只保留上限前真实目标最优的候选，并将该起点标记为未收敛，不能把随后廉价罚值循环的停止误判为收敛。此前缺少 checkpoint 的第二起点长时运行已中止，日志独立保留，不用于任何最终估计。

本次复算首起点在 167 次迭代收敛，目标 `0.1092579268675`。第二起点停在 Stata 自带 NM 的第 52 次迭代，未再次回调目标函数，所以目标函数内部的计时器不能控制这个 vendor 阶段；到 600 秒时执行外部中止，保留目标 `0.1543419762698` 的 checkpoint，明确未收敛。随后不再估计起点，只恢复较优的已收敛首起点并计算诊断。未来建议运行 `03_corner_bounded.sh`：两个 Stata 起点各在独立进程中接受操作系统 `timeout`，即便 vendor 代码不再回调也能终止；checkpoint 记录收敛标志，后处理另启进程。历史缺少该字段的首起点仅在目标数值与本次已验证收敛的 legacy checkpoint 一致时保留其收敛状态。

家庭倍率有 `1e-5*sum(eta^2)` 的明确弱数值惩罚，因此点估计是受限、轻度正则化的 SMD pilot。基期食物预算与偏好独立、外部价格可用性以及有限省份价格变异都是尚需进一步研究的识别假设；本 pilot 不声称已修正所有预算内生性。

## 响应的定义

```text
Q_i = E[q_i] = pi_i * E[q_i | q_i>0]
total finite log response = participation response + conditional response.
```

报告的响应为固定偏好 draw 下 `+/-2.5%` 扰动的有限对数响应，非伪精确的无穷小导数；同时检查 Hicksian 水平导数的对称、齐次与曲率。Hicksian 逐 draw 保持基期效用，不把聚合 Marshallian 加上 `w_j*expenditure_elasticity` 当作随机角点模型的真正补偿响应。

估计中预算除以训练母体的预算中位数，平移参数因此处于相同的归一化单位。响应文件里的平均量和条件平均量已经乘回预算尺度，是按价格指数计量的购买量等价单位；它们不是公斤，也不应与原始交易 `Volume` 直接拼接。

食品预算响应不是家庭收入弹性。收入链式效应需要另一阶段的收入区间模型、食品预算映射与直接偏好响应假设，不在此程序内悄悄改名。本轮不做 bootstrap，不报告抽样 p 值或置信区间。优化收敛、矩 Jacobian 和样本外误差不是统计显著性检验。

## 本次实际结果与资格

参数已实际估计并完成全部响应文件。基准预算为训练母体中位数 `160.24` 元/人/月；代表性价格为加权训练支持点平均价格。四类家庭、八类食品的 32 个补偿自价格有限响应范围为 `-1.6701` 至 `-1.0143`，Marshallian 自价格为 `-1.8369` 至 `-1.2450`，预算响应为 `0.9365` 至 `1.2886`。这些是受限效用内建正常品/替代规则下的点响应，**不是数据独立证明经济理论符号成立，也没有抽样显著性**。全交叉价格矩阵、参与/条件均量分解、四类家庭的五预算点曲线分别保存在对应 `price_response`、`budget_response_curve` 文件；汇总的 32 行在 `own_price_and_budget_at_median_all_4_families.csv`。

同一参数的 16/64/256-draw 目标值为 `0.109258/0.108598/0.119507`，256 相比 16 高约 9.4%，说明有限积分误差不能忽略。256-draw、`+/-0.025` 参数差分矩 Jacobian 的数值 rank 为 20/20，条件数 74.5131；这不是正式的强识别或显著性检验。61440 个真实支持点随机需求中，无效根、预算不闭合、负量均为 0；128 个局部补偿差分点的最大 Slutsky 特征值为 `5.72e-17`，对称误差 `1.22e-11`。全部正购买的加权训练支持点观测为 39.60%，模型为 45.15%；训练母体为 37.98%，留出母体为 36.10%。

留出拟合不合格的问题必须保留：水果预算份额观测 17.68%、预测 13.54%，猪肉观测 11.70%、预测 17.98%；水果参与率观测 98.24%、预测 87.21%，蔬菜观测 96.90%、预测 88.59%。不少留出 RMSE/Brier 也未优于常数训练均值基准。因此此扩展仍标为 `restricted_pilot_diagnostic`，不能称最终合格预测或完整零消费解决方案。数值求解成功、符号满足理论以及有限矩 Jacobian满秩均不能替代拟合检验。

后处理曾因一个超过 Stata 32 字符上限的状态变量名中断，模型、响应及 Jacobian 输出已 checkpoint。最终通过 `03_corner_finalize_status.do` 从真实输出恢复状态并以相同 theta/256 draw 重算全正购买联合概率；没有新增估计起点。`fit_status.csv` 已标记 `postprocessing_pending=0`，最终文件验证日志为 `03_corner_verify_delivery.log`。外部中止的第二起点只有最后 checkpoint 的评估计数，不能冒称完整总评估次数；输出字段已明确为 `evaluations_at_last_checkpoint`。
