# 自由端点 MAIDADS 的自然单纯形检查

本补充只处理 MAIDADS 参数可行域和优化器的数值问题。不改变原始支出、价格、样本或食物分类；不按弹性符号选择模型；不使用 bootstrap；不采用 Slutsky 的 Cholesky 重参数化。

## 为什么补充这一参数化

原先通过 softmax/logit 表示低、高效用端边际份额。它能保证加总，但不能用有限 logit 表示精确零。实际粗分组模型的高端水产品份额，以及老年家庭模型的低端其他肉、高端水产品份额，接近零并触及计算限值。这是参数化边界问题，需要和最低预算导致的承诺支出可行域问题分别检查。

`maidadssimplexfit.ado` 使用 K - 1 个自然份额坐标，最后一类由加总约束确定。两个份额向量都投影到非负单纯形，允许精确零；低端承诺量 δ 和高端承诺量 τ 全部保留为自由非负参数。模型内每一类必须至少在一个边际份额端点得到支持，即 α_i + β_i > 0。两个端点都为零时，估计器拒绝该候选，直接预测也明确报错，不通过 0 × log(0) 或除以零继续运行。

数值求值分别计算 logistic(-u) × α 与 logistic(u) × β，而不是以 `1 - logistic(u)` 计算尾部权重。因此 u = 50 时 α 项不会因为舍入成零而消失。logistic 还按正负分支计算，避免 ωu = ±1000 时指数上溢。

## 优化和合格检查

- 带单纯形投影的 BFGS 允许进入和离开经济学边界；活跃面 BFGS 对正份额面进一步优化。
- 采用完整 K 类的自然单纯形投影 KKT 分数，以及其他参数的实际盒约束投影残差，而不是仅检查 logit 梯度或把近边界梯度直接设零。份额接近零时，logit 梯度过小不能替代自然参数的一阶条件。
- 已达到预设 1e-4 分数阈值的 BFGS 点不再进行可能受浮点误差影响的无条件末轮优化。
- 对非常低噪声、曲率很高的模拟数据，最多 8 次自然活跃面 QML Gauss-Newton 分数细化减少分数。只接受可行点，目标函数允许的数值误差最多 1e-12，并要求完整 KKT 分数下降。其残差协方差白化仅是优化器度量，不是 Slutsky 曲率重参数化，也不作为标准误。
- 计算正参数活跃面的 Jacobian 秩，以及包括内向边界方向的完整自然参数 Jacobian 秩。合格要求两者均达到其维数；秩检查是局部数值诊断，不证明全局识别。
- 活跃面使用可行的中心差分；精确零份额和非负参数边界使用内向单侧差分。不对越过单纯形或预算可行域的差分冒称通过。
- 检查各观测预算闭合、效用方程、Eu/Q、超额预算份额和弹性的数值差分。效用根在 [-50, 50]、步长 0.25 的网格上检查，并补充导数变号临界点；这是有限范围的数值检查，不是全域唯一性证明。

## 模拟验证

`02_test_simplex_edges.do` 构造三类、精确 α3 = 0 与 β2 = 0 的原生模型，验证效用根、活跃面及边界内向导数、完整 K 类 KKT 投影和可行单纯形重复投影保留精确零。u = ±50 时最小受支持边际份额为 7.7e-23；ω = 20 时仍无指数上溢。

`synthetic_endpoint_simplex` 还从上述自然端点开始重新估计全部 δ、τ 和其他参数。最终完整 KKT 分数 4.48e-6；完整自然秩 12 / 12、活跃面秩 10 / 10；480 个效用根数值检查全部通过。真值与估计均出现一个精确零 α、一个精确零 β，未强制固定这两个零。

## 可复现调用

运行脚本为 `code/02_estimate_simplex.do`，参数顺序为：输入 CSV、输出目录、`maidads` 或 `aidads`、K、起点数、最大 BFGS 迭代数、样本筛选表达式、已有自然参数输出目录。通过 shell 调用且不筛选时，筛选表达式明确填写 `1`，不能依赖空 shell 参数。

```stata
adopath ++ "/root/data/Paper/央视数据/cctv_maidads_20261011/ado"
maidadssimplexfit, expenditure(m) prices(p1 p2 p3) shares(w1 w2 w3) ///
    model(maidads) outdir("output_directory") starts(2) iterate(400)
```

已有原生估计结果可通过 `warmdir()` 指定，读取自然 α、β、δ、τ、ω、κ，而不是将旧 logit 系数误当自然系数。`02_audit_simplex.do` 可在不重新估计或改变参数的情况下刷新数值检查。旧 canonical、tangent 和 warm 输出未覆盖。

## 解释限制

目前可称为通过局部数值检查的自由端点估计点，不可称为已证明的全局最优点。额外的不同起点检查放在独立 `*_simplex_multistart` 目录，不覆盖上述点。

两起点检查均已完成。粗分组两起点的目标函数一致到 1e-9 量级，最佳 KKT 分数为 1.43e-6；老年家庭组最佳分数为 9.04e-7。粗分组复核把原点中仅为 1.37e-7 的 τ2 估为精确零，其他参数与弹性仅有微小数值差异。重复到达同一局部解增加数值可信度，但不证明全局最优。

八类粗分组估计的是分组平均预算对应的条件需求关系，不是每个微观家庭精确零消费的模型。承诺量可能使底层很小的家庭预算不可行。将参数用于个人预测时必须保留预算域与覆盖率检查；不得为凑齐预测而删除不适用家庭、补小常数或把预算抬高。

本命令不提供 `e(V)`。参数或弹性的 p 值和区间未由本次点估计生成；边界、收入分档、价格代理、分组与第一阶段的不确定性也不会因为数值合格而消失。完整模型选择、角点扩展和省份收入增长预测见主报告。
