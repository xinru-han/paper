- 类型后缀：`-1` 成本收益；`-2` 费用和用工；`-3` 化肥投入（饲养业无-3）。
- 第1章（`1-x-x`）为全国平均按年份列；第2章起"各地区"表才是分省表：列=省份（首数据列"平均"），行=科目。

### 关键科目（-1表）
每亩块：主产品产量、产值合计、主/副产品产值、总成本、生产成本、物质与服务费用、人工成本、家庭用工折价、雇工费用、土地成本、流转地租金、自营地折租、净利润、现金成本/收益、成本利润率；每50公斤块：平均出售价格、总成本等（与每亩块同名重复！）；附：每亩用工数量(日)、商品率等。

### -2表（费用和用工）
直接费用[种子费/化肥费/农家肥费/农药费/农膜费/租赁作业费(机械作业费/排灌费/畜力费)/燃料动力费/技术服务费/工具材料费/修理维护费/其他直接费用]、间接费用[固定资产折旧/保险费/管理费/财务费/销售费]、人工成本[家庭用工折价(家庭用工天数、劳动日工价)/雇工费用(雇工天数、雇工工价)]、附[每亩种子用量/化肥用量/农膜用量]。

### -3表（化肥投入）
每亩化肥金额与**每亩化肥折纯用量(公斤)**，分氮/磷/钾/复混。

## 4. 坑清单

1. **OCR续表缺页（最大问题）**：大豆2019/2020/2022/2023仅6省（真表≈13省）；粳稻2020仅6省（应12）；中籼稻2020/2022仅6省；玉米2019、小麦2021、中籼稻2023缺部分省的费用用工科目。需对照PDF补录。
2. **xls加密**：2017、2018、2019卷加密，`msoffcrypto` + 密码 `VelvetSweatshop` 可解（已验证，msoffcrypto-tool 6.0.0已安装）。
3. **重复行名**：总成本/生产成本/净利润在"每亩"与"每50公斤"块各出现一次；OCR库row_group 98%缺失，需按source_row_index顺序/数值大小判别（每亩值≫每50公斤值）。
4. 2007卷`2-12-*`是`2-06`玉米的完全重复，勿计入。
5. 省份数缩减是真实的：小麦21省(2004)→13省(2024)；玉米20-22省稳定；大豆约13省。
6. 2025合表xlsx横向拼两块需去重复header列；表尾"数据狂公众号"水印行需过滤。
7. 单位稳定；2004数据年起新口径，与2003前不衔接。
8. 2019卷有"附录二 各省劳动日工价一览表"可交叉核对。
