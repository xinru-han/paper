# 结果汇总（2026-07-08，终版：底库修正+两轮补录+方法修复后全量运行）

数据：省级面板 2004–2024，5 要素（labor / mach / fert / seed / other=numeraire）。
底库 OCR 污染值已按 PDF 直读修正（`out/base_conflicts.csv` 1,573 值）、续表缺页
补录两轮合入（`data/yearbook_patch_ocr_gaps.csv` 4,823 行 +
`data/yearbook_fix_rapeseed2023.csv`），小麦缺 2012 年由 w_seed 省内对数插值救回。
样本：corn 427 / wheat 325 / soybean 240 / japonica 278 / mid_indica 237 /
early & late_indica 189 / peanut 222 / rapeseed 302（cotton 79 排除主分析）。

**基线规格 = "cc"**：ITSUR + Terrell (1996) 逐观测曲率惩罚（κ=1e6），省 FE。
**方法修复（评审 F-4）**：份额方程含省截距时，成本方程按 Shephard 引理加入
Σ fe_np·lnw_n 可积性项——修复后玉米 plain 凹性 63.7%→68.9%，numeraire
不变性 ~1e-11，Törnqvist 分解残差 0.180→0.007。修复后 9 品种 cc 拟合份额
凹性 96.8–100%（观测份额处 98.3–100%）、单调性 100%。

## 3. 技术偏向 B_n = λ_nt / S̄_n（cc）

粮食主粮（corn −0.6%、japonica −2.2%、mid_indica −0.9%、early/late_indica
−2.2%/−2.3% 每年）一致表现**劳动节约**且机械使用偏向（B_mach +0.4% ~ +1.9%）；
wheat/rapeseed 的 B_labor 接近零（机械化早已完成），soybean/peanut 为小幅正
（黑龙江主导样本/经济作物）。LR 检验 9 品种全部拒绝 Cobb-Douglas、
Hicks 中性与无技术变迁。

## 4. 诱致性创新两阶段（S2 general index，pooled 5 大粮作）——【不支持 Hicks】

方法修复（评审 F-3/F-2）：general index 系统只估份额方程（use_cost_eq=FALSE，
年哑变量与成本方程可积性冲突）；第二阶段 SE 改按年聚类（vcovCL, HC1）。
节约偏向定义 sb_n=−Δδ_n。结果：labor Σψ=−0.257 (t=−2.56)、
mach Σψ=−0.117 (t=−2.61)：**Σψ<0 表示滞后工资相对上涨之后出现的是劳动使用
（δ_labor 上移）方向的移动，与 Hicks 诱致性预期（Σψ>0）方向相反**。
labor 的 placebo（未来一期价格 t=−3.9，量级达主效应 72%）仍显著，一致解释：
年哑变量吸收了 γ 未完全捕捉的全国性价格-份额共同趋势，第二阶段识别的是
残余价格效应而非诱致性技术响应。**该节不能作为诱致性创新的证据**；
候选修补（未实施）：省×品种层面第二阶段、更长滞后（k=1–5）、去趋势。

## 5. Törnqvist 成本增长分解（名义，2004–2024）

玉米全国：亩成本对数增长 1.10，其中要素价格贡献 1.41（劳动价格独占 0.93），
技术进步抵消 −0.36，产量规模 +0.04，残差 0.007（F-4 修复后由 0.18 降至近零）。
2013 年分段：前期 dlnC=1.01（价格 1.16、劳动 0.84）vs 后期 dlnC=0.10
（价格 0.31、劳动 0.20）——2013 年后价格推动与技术抵消同时减弱，
与刘易斯转折后工资增速放缓叙事一致。

## 6. 份额 OOS 预测（训练 ≤2021，留出 2022–2024）

translog RMSE 0.027–0.049，全面优于 Cobb-Douglas（0.051–0.076）；
与随机游走互有胜负（early_indica、wheat 胜，其余略逊 0.003–0.010）——
面板短期份额惯性强，属预期内。

## 8. 稳健性：雇工工价替代统一日工价

价格比）替换为 w_labor_hired（雇工工价，省际有真实变异；省内对数插值+
