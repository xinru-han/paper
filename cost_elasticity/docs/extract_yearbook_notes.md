## 2. 实施中的关键发现（审计报告之外）

1. **表号漂移比审计写的更广**：不止2007卷，**2008卷**同样是大豆2-9/花生2-10/油菜籽2-11（2-7为高粱、2-8谷子），2009卷起才是2-7/2-8/2-9。脚本改为**按 -1 表标题扫描解析表号**（`resolve_table`），并对每个读入文件做表号前缀+品种名标题断言，不再硬编码。
2. **2008卷标题错别字**：`早灿稻/晚灿稻`（灿→籼），规范化函数已处理。
3. **2007卷第3章文件名不补零**（`3-1-1.xls`，第2章为`2-06-1.xls`）。
4. **2019卷棉花表"平均"列写作"棉花平均"**，已归入 national 层。
5. **OCR跨表串页污染**：2024卷（数据年2023）棉花成本收益表内容被OCR挂到"油菜籽化肥投入情况"表页下，曾污染油菜籽2023的总成本（山东2894/陕西3317等棉花值）。已加**科目↔表标题一致性过滤**（-1科目只认"成本收益"标题、-2科目只认"费用和用工"、化肥折纯只认"化肥投入"），污染消除，油菜籽2023恢复15省合理值。

## 3. QC 结果（脚本内 assert，全部通过）

- 恒等式检查共评估 6,932 组，违规 315（**4.55% < 5%阈值**），全部来自 **OCR 年份**；
  xls 年份（2006–2018、2024）三项恒等式**零违规**。
  - msf_sum 209（多为OCR分项缺失按0计入或个别数字误读，n_have≥12才评估）
  - labor_sum 66（典型如大豆2019黑龙江：OCR的人工成本=家庭用工折价，缺加总行）
  - total_cost 40
  - 按年分布：2004:112, 2005:49, 2019:54, 2020:46, 2021:5, 2022:29, 2023:20
- 范围粗检（总成本100–4000、日工价5–250、产量20–1500/棉花放宽到5）：**0 违规**。
- **接缝一致性**（玉米/小麦总成本增长率，OCR↔xls切换处）：76个省级接缝，|增长|>60% 者 **0**：
  - corn 2005→2006: n=22, 中位数 +5.5%, 区间 [-11.9%, +12.8%]
  - corn 2018→2019: n=20, 中位数 +0.5%, 区间 [-6.5%, +5.5%]
  - wheat 2005→2006: n=21, 中位数 +5.0%, 区间 [-16.9%, +11.9%]
  - wheat 2018→2019: n=13, 中位数 +1.8%, 区间 [-3.0%, +5.5%]
- 抽查核对（与原表逐值一致）：玉米2015河北（总成本983.2/产量482.04/日工价78）、
  小麦2010河南（总成本627.77/每亩块口径、平均出售价格96.74=每50公斤口径）、
  大豆2019黑龙江（OCR，总成本760.09每亩口径，6省与已知缺口一致）。

## 4. 消歧与口径说明

- xls -1表按行序状态机分块：每亩块 →（"每50公斤主产品"标记）→ 每50公斤块（只取平均出售价格）→（"附："）→ 附块（取每亩用工数量）。
- OCR 同键多行取最大值为每亩口径；平均出售价格取中位数（仅每50公斤口径，重复行来自OCR重表）。
- -1/-2表重名科目（物质与服务费用/人工成本/家庭用工折价/雇工费用）优先取 -1 表值。
- 2007卷2-12-*（2-06玉米重复表）因按标题解析表号自动绕开，未计入。

## 5. 遗留问题

1. **OCR续表缺页**（审计§4.1，均已在 `out/coverage_gaps.md` 核实）：大豆2019/2020/2022/2023、
   粳稻2020、中籼稻2019/2020/2022 仅~6省；早/晚籼稻2005/2019/2020仅4省；花生2019仅6省；
   大豆2004/2005仅6省（审计未列，属同类缺口）。需对照PDF补录后可增量并入。
2. **棉花2023整年缺-1表**（OCR只入库了费用用工与化肥表，总成本/产量缺），`coverage_gaps.md`
   已动态标出；需从2024卷PDF第157页前后补录。
3. OCR年份恒等式违规315条留在 `out/qc_violations.csv`，多数是分项缺失而非主变量错误；
   使用分项科目做2004/05、2019–23年分析时建议逐条核对或以xls年份为准。
4. 生猪未做（任务范围外）；无省级"稻谷平均"，如需稻谷需四稻自聚合。
