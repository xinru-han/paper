# 种粮盈亏预测与预警体系：研究设计（v1）

*2026-07-07 起草；本文件是研究的总纲，代码与论文以此为准。*

## 1. 研究问题与贡献

**核心问题**：在年初～生长季内可观测的信息集下，能否提前预测各省主要粮食作物当年的亩均盈亏（净利润水平与亏损概率），并据此构建分级预警体系？

相对于既有工作（0429 版：玉米单作物、随机森林、随机 80/20 切分）的升级：

1. **多作物**：玉米、小麦、大豆、四类稻谷（早/中/晚籼、粳稻），省×作物×年面板（2004–2024），样本量从 381 扩至约 2,600。
2. **严格的时序外推验证**：预测年份 t 时只用 t-1 年及以前的成本收益信息 + t 年内可观测的高频信号（投入品价格、收购价、气象），扩窗滚动验证（expanding window），杜绝随机切分带来的信息泄漏。
3. **前沿模型对比**：计量基准（固定效应 OLS / Logit）→ 树集成（RF、XGBoost、LightGBM）→ 表格深度学习（FT-Transformer）→ 表格基础模型（TabPFN v2.x）→ 符号回归（PySR，产出可解释预警公式）。
4. **可解释性与预警落地**：SHAP 识别关键可观测驱动因素；符号回归提炼简约预警规则；概率分级（红/橙/黄/蓝）预警体系并做 2023/2024 样本外演示。

## 2. 数据

### 2.1 因变量（目标）

来源：《全国农产品成本收益资料汇编》省级分作物数据（已清洗为 `yearbook_long.csv`，10 作物 × ≤30 省 × 2004–2024 × 40 指标）。

- **净利润（元/亩）** = 产值合计 − 总成本。回归任务目标。
- **亏损指示** loss = 1(净利润 < 0)。分类任务目标。
- 辅助目标（稳健性）：现金收益口径 = 产值合计 − (总成本 − 家庭用工折价 − 自营地折租)，反映农户实际现金盈亏。

### 2.2 特征（信息集分层）

预测 t 年盈亏时，特征按可获得时点分三层：

**L1 惯性层（t-1 及以前，来自汇编）**
- 滞后净利润、滞后产值、滞后总成本及构成（人工/土地/化肥/机械/种子等成本份额）
- 滞后亩产、滞后出售价格、滞后成本利润率
- 2 阶滞后与 3 年移动趋势

**L2 年内信号层（t 年内旬度/月度可观测，预警的核心价值）**
- 发改委投入品价格（省×年）：尿素、复合肥、磷肥、农膜、农药、机耕机收费（`prices_ndrc_annual.csv`，2003–2025）
- 主产区原粮收购价旬报（省×品种，2005–2025）：播前(1–4月)均价、生长季(4–9月)均价、同比变化、年内波动率
- 气象（省×月，1973 基准距平）：生长季气温/降水及其距平

**L3 结构层**
- 作物类别、省份/区域、时间趋势、政策虚拟变量（如 2016 年玉米临储改革）

> 注意：L2 中"全年均价"含收获后信息，仅用于事后分析版本；预警版本（主报告）只用截至 9 月的信号，模拟"秋收前预警"。

## 3. 预测任务设定

- **任务 A（回归）**：预测净利润（元/亩）。指标：RMSE、MAE、R²（out-of-sample），分年份报告。
- **任务 B（分类）**：预测亏损概率。指标：AUC、PR-AUC、Brier、以及预警场景下的召回率@精确率（漏报亏损的代价高于误报）。
- **验证协议**：扩窗滚动起源验证。训练 2004–(t-1) → 预测 t，t = 2015, …, 2024（10 个测试年）。所有模型、所有超参搜索都在训练窗内部再做时序切分，测试年绝不参与任何拟合。
- 汇报口径：10 个测试年的加权平均 + 分年曲线；按作物分解。

## 4. 模型体系

| 类别 | 模型 | 角色 |
|---|---|---|
| 计量基准 | 双向固定效应 OLS / Logit（省+年FE 用作物FE替代年FE以免泄漏，只用可外推变量） | 可解释基准 |
| 传统 ML | 随机森林（对齐 0429 版）、XGBoost、LightGBM | 强基准 |
| 表格深度学习 | FT-Transformer（rtdl 实现，类别特征 embedding） | 前沿之一 |
| 表格基础模型 | TabPFN（v2.x，上下文学习，小样本表格 SOTA） | 前沿之二 |
| 符号回归 | PySR（限制算子集，复杂度惩罚） | 可解释公式，预警规则 |

- 类别特征（省、作物）：树模型用原生类别/目标编码（仅在训练窗内拟合编码），FT-Transformer 用 embedding，TabPFN 用序数编码。
- 缺失值：树模型原生处理；深度模型用训练窗内中位数插补 + 缺失指示。
- 集成：取各测试年表现最优的前 2–3 个模型做简单平均，作为"预警引擎"。

## 5. 关键因素识别

- SHAP（TreeExplainer 用于 GBDT；Kernel/Permutation 用于其余）：全局重要性、依赖图（如尿素价格×净利润非线性）、分作物差异。
- 与固定效应回归的系数对照，检验 ML 发现是否与经济直觉一致。
- 符号回归输出 3–5 条简约公式（如 loss_prob ≈ f(滞后利润, 收购价同比, 尿素价)），作为"手算版"预警规则。

## 6. 预警体系设计

1. **概率输出**：预警引擎输出各省×作物当年亏损概率 p。
2. **分级**：蓝 p<0.3、黄 0.3–0.5、橙 0.5–0.7、红 ≥0.7；阈值由训练期成本敏感优化（漏报:误报 = 3:1）校准。
3. **幅度**：回归模型给出预期亏损幅度（元/亩），与概率联合成预警矩阵。
4. **演示**：2023、2024 年全作物×省预警地图/表格，与实际盈亏对照，报告命中率、漏报率。
5. **规则备份**：PySR 公式版预警卡片，供无模型环境使用。
