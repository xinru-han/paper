## 3.3 变量分类框架

数据按主题分为以下大类（括号内为农户问卷 2021 年各分类的列数）：

### 3.3.1 家庭成员信息（~350列）

包括家庭成员 1-10 的详细人口和社会经济属性：

## 4. 面板数据构建指南

### 4.1 农户面板

```
关键 Key: ['户代码', '年份']
核心标识: ['省名', '省代码', '县名', '县代码', '乡（镇）名', '行政村名', '行政村代码']
合并方式: pd.concat([df2019, df2020, ..., df2024], axis=0)
```

**注意事项**：
1. 2019-2020 列结构（1986列）与 2021-2023（2817列）不同，需对齐列名后拼接
2. 2024 年列结构再次变化（2365列）
3. 建议以 2021-2024 为主面板（列较多），2019-2020 作为补充
4. 大量列缺失率 >50%（稀疏的重复表），需按需选择

### 4.2 村级面板

```
关键 Key: ['行政村代码', '年份']
```

村级样本量小（9-27村），适合作为农户模型的控制变量，不适合独立做统计分析。

### 4.3 合并层级

```
农户面板 ← merge ← 村级面板（by 行政村代码 + 年份）
```

## 5. 适用于机器学习/建模的建议

### 5.1 高价值核心变量（建议优先提取）

**被解释变量（Y）**：
- 家庭总收入 / 农业收入 / 非农收入
- 种植业销售总收入
- 畜牧业销售总收入

**解释变量（X）— 人力资本**：
- 家庭成员：年龄、性别、健康、教育年限、是否受培训
- 户主：年龄、健康、教育

**解释变量（X）— 土地与资本**：
- 耕地面积（承包 + 未计入承包的）
- 生产性固定资产总值
- 园地/林地/草地面积

**解释变量（X）— 劳动力配置**：
- 家庭劳动力人数
- 外出务工人数/务工天数/月工资
- 在家务农时间

**解释变量（X）— 技术/信息**：
- 互联网使用（0/1）
- 是否获得农业技术培训
- 农业保险参与

**工具变量/外生冲击**：
- 因灾减产（灾害类型）
- 村级地形、是否为贫困村/革命老区
- 土地流转价格（村级均价）

### 5.2 特征工程建议

1. **家庭成员长格式转换**：每个成员相关变量（1-10号）应 pivot 为长表，用于分析家庭结构
2. **种植业/畜牧业宽→长转换**：以 `_产品编码` 为 key，按产品编号 1-N 展开
3. **年龄分组**：0-16（儿童）、17-30（青年）、31-50（壮年）、51-65（老年）、65+
4. **非农就业比例**：外出劳动力 / 总劳动力
5. **农业经营强度**：产量/播种面积 = 单产

### 5.3 缺失值处理

- 种植业表/畜牧业表：大多数家庭只经营 1-5 种产品，其余列为系统缺失（NA），非随机缺失
- 家庭成员表：一般 2-6 人，编号>6 的成员全为 NA
- 建议先筛选有数据的列（非空率 > 20%）再做分析
- 二元变量（是否参与 ××）：缺失通常表示"否"

### 5.4 数据类型注意事项

- 所有数据存储为 Excel（.xlsx），读取后类型为 `object`，需批量转换为 numeric
- 问卷中包含大量"其他（请注明）"文本型字段，需单独处理
- 编码类变量（产品编码、灾害编码等）需与编码字典匹配方可解析
- 满意度、效果类变量通常为有序尺度（1-5），可直接作序数变量
