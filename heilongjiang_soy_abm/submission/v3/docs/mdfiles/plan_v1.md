## 1. 研究问题与定位

### 1.1 核心研究问题

- **RQ1（行为）**：在预期收益差（价格×单产−成本）与补贴差的驱动下，农户种玉米、种大豆的概率与大豆面积份额如何被决定？对"补贴差每变动 100 元/亩""豆粮比价每变动 0.1"的响应有多大？
- **RQ2（政策）**：什么政策组合（生产者补贴差、米豆轮作补贴、价格环境、成本保险）能把大豆种植概率/面积份额推到目标水平？财政成本几何？成本有效性前沿是什么形状？
- **RQ3（异质性）**：政策响应在经营规模、户主年龄、兼业程度、县域（积温带）之间如何分化？

### 1.2 方法定位："微观计量校准 + ABM 模拟"两层结构

1. **计量层**：用 2019–2024 农户面板估计种植选择方程（参与 + 份额），得到收益/补贴响应等行为参数及其方差-协方差矩阵。
2. **模拟层**：ABM 以估计参数驱动异质性农户逐年决策，加入价格预期形成、轮作农艺效应（豆茬增产/大豆重迎茬减产）、村内同伴效应与随机冲击，向前模拟 2025–2030 并做政策实验。

**卖点（区别于已有文献）**：
- 行为参数来自微观面板计量估计而非主观设定（多数已有 ABM 的弱点）；
- 利用 **2022 年大豆扩种行动**（中央一号文件"大豆和油料产能提升工程"，黑龙江补贴差扩大 + 强政策信号）作为已知政策冲击做**事件验证**，检验模型外推能力；
- 检验"补贴 1 元 vs 市场收益 1 元"边际效应是否等价（政策显著性/salience 问题），其本身即可作为一个论文结果；
- 输出**财政成本—大豆扩种效果前沿**，直接对接政策需求。

### 1.3 目标发表与体裁

- 英文：Agricultural Systems（ABM 主阵地）/ Food Policy / China Agricultural Economic Review；
- 中文：《中国农村经济》《农业技术经济》或智库要报；
- ABM 论文需附完整 **ODD 协议**（Overview–Design concepts–Details）技术附录，Phase 7 一并产出。

### 1.4 概念框架（文字版）

```
[政策杠杆: 玉米/大豆生产者补贴、轮作补贴、保险]
[市场环境: 玉米价、大豆价、亩均成本]
        ↓
农户预期亩净收益差 Δπ̂ ──→ 种植决策 P(种大豆)、大豆份额 s

        ↓

```

## 2. 数据、口径与外部资料

### 2.1 主数据

- 户问卷 2019–2024（175 / 174 / 530 / 529 / 956 / 992 户），村问卷 2019–2024；
- **主分析面板：2021–2024**（列结构较全、样本较大）；2019–2020 用于描述统计与稳健性；
- 面板键：`户代码 × 年份`；村级键：`行政村代码 × 年份`；县：双城区(230113)、桦南县(230822)、大箐山县(230725)——三县分属不同积温带，天然提供玉豆适宜性梯度。

### 2.2 决策口径（重要设定，写入论文方法部分）

- **决策单元**：农户（户级）。地块层更优（轮作可直接观测），但地块跨年可追踪性未知——Phase 0 评估后若可行则升级（见 §11-B）。
- **时间步**：年度（春播决策）。
- **作物集合**：{玉米, 大豆} 为决策作物；水稻及其他作物归入"其他"，其面积视为户级准固定（取历史均值），不进入选择边际。理由：玉豆竞争主要发生在旱地，水田—旱地转换成本高、非年度边际。
- **决策用地基数**：`B_it = 玉米播种面积 + 大豆播种面积`（户×年）。核心内生量：大豆份额 `s_it = 大豆面积 / B_it ∈ [0,1]`。
- **报告口径（与研究目的直接对应）**：
  - P(种大豆)_it = P(s_it > 0)
  - P(种玉米)_it = P(s_it < 1)
  - P(兼种)_it = P(0 < s_it < 1)

## 4. Phase 1 面板构建

- **T1.1** 作物长表：宽 → 长（产品 1–N 展开），保留 {户代码, 年份, 产品编码, 播种面积, 产量, 因灾减产, 保险赔偿, 自食量, 销售量, 销售收入} → `panel_crop_long.parquet`。
- **T1.2** 户年主表：
  - `B_it`、`s_it`、`plant_soy`、`plant_corn`、`plant_both`；
  - 滞后项：`s_{i,t−1}`、`plant_soy_{i,t−1}`；
  - 轮作代理变量（户级近似）：轮作重叠强度 `RotIn_it = min(s_it, 1−s_{i,t−1})`（今年豆 × 去年玉，用于轮作补贴合格面积近似）；重迎茬强度 `Rep_it = min(s_it, s_{i,t−1})`。
- **T1.3** 户特征：户主年龄/教育年限/健康、家庭规模、劳动力数、外出务工人数与总天数、非农收入占比、承包与实际经营耕地、转入/转出面积、生产性固定资产年末估值、是否参加农业保险、互联网使用（0/1）。
- **T1.4** 村级合并：地形、是否贫困村、基础设施（简单加总指数）、农技推广；构造同伴变量 `Peer_{v,t}` = 村内**除本户外**其他户上年大豆面积份额（leave-one-out；村内户数 <5 的标记，稳健性中剔除）。
- **T1.5** 质检：玉豆面积 ≤ 实际经营耕地（超出者核查复种/口径）；单产 1%/99% winsorize；标记连续户子样本。

**DoD**：`panel_hh.parquet`；phase1_report 含各年 N、大豆参与率、s 分布、进入/退出统计（此表本身即论文表 1 素材）。

## 5. Phase 2 收益、价格与政策变量

- **T2.1 价格**：`p = 销售收入 / 销售量`（户级单位价值）→ winsorize → 聚合为 **县×年×作物中位数** `P_{c,county,t}`；缺失单元回补顺序：县内相邻年插值 → 省级中位数。CPI 平减（2020=100）。⚠️黑龙江 CPI 序列待核实（§10.2-4）。
- **T2.2 单产预期 ŷ**：户历史均值向县×作物均值收缩（shrinkage 权重 `n_i/(n_i+2)`，n_i 为该户该作物观测年数）；新户直接用县均值。
- **T2.3 茬口效应估计（ABM 关键机制参数）**：
  - 玉米方程：`log(y_corn,it) = δ_rot·s_{i,t−1} + 户FE + 年FE + e` → δ_rot（豆茬增产效应）；
  - 大豆方程：`log(y_soy,it) = −δ_rep·s_{i,t−1} + 户FE + 年FE + e` → δ_rep（重迎茬减产效应）；
  - 若不显著或样本不足：采用文献区间（豆茬玉米约 +8%~15%；大豆重迎茬约 −10%~−30%），**明确标注"文献值"并纳入敏感性网格**。
- **T2.4 成本 c_{c,t}**：
  - 方案 A：问卷内如有分作物亩均投入列则直接构建；
  - 方案 B：《全国农产品成本收益资料汇编》黑龙江玉米/大豆亩均**现金成本**（推荐口径，贴近农户短期决策边际）。
  - **⚠️STOP-2**：报告问卷内成本信息可得性，请用户拍板 A/B；若选 B，请求按 §13 模板填写 `data/external/cost_template.csv`。
- **T2.5 补贴标准表** `data/external/subsidy_standards.csv`（county × year）：字段 {玉米生产者补贴, 大豆生产者补贴, 米豆轮作补贴, 耕地地力保护补贴(不分作物，记录但**不进入** Δπ), 来源, 状态}。
  - 量级备忘（仅供核对方向，**非最终值**）：近年黑龙江大豆生产者补贴大致在每亩 200–370 元区间、玉米在每亩 10–70 元区间、轮作补贴曾按每亩 150 元标准执行——逐年逐县数值必须以官方文件为准。
  - **⚠️STOP-3**：生成模板交用户核实填写（或经用户授权联网检索官方文件后，由用户复核）。
  - **为何不用问卷户报补贴构建政策变量**：户报为全年合计、跨作物混合且含滞后发放，测量误差大、并与面积机械相关（除以面积会引入 division bias）；户报补贴仅用于 T2.8 交叉校核。
- **T2.6 预期与信息时点（重要设定）**：
  - 价格预期：自适应 `p̂_t = λ_e·P_{t−1} + (1−λ_e)·p̂_{t−1}`；基线 λ_e = 1（静态预期），λ_e 在 Phase 5 校准；
  - 补贴预期：黑龙江生产者补贴标准通常在**播种之后**才正式公布 → 基线设 `ŝ_t = s_{t−1}`（上年标准）；敏感性设定：完全预见 `ŝ_t = s_t`；**2022 年单独按"强政策信号"处理**（一号文件明确扩豆、预期取当年实际）。三种时点设定都跑，写入稳健性。
- **T2.7 预期亩净收益与差值**：
  - `π̂_c,it = p̂_c,county,t · ŷ_c,i,t − c_c,t + ŝ_c,county,t`（c ∈ {玉米, 大豆}）；
  - `Δπ̂_it = π̂_soy − π̂_corn`；分解 `Δπ̂ = Δm̂（市场收益差）+ Δŝ（补贴差）`。
- **T2.8 校核图**：户报补贴总额 vs 标准×申报面积 的散点与相关系数（诊断用）。

**DoD**：`analysis_panel.parquet`；表 1 描述统计；趋势图（分县大豆份额 2019–2024、玉豆价格与豆粮比价、补贴差时序）。

## 6. Phase 3 行为参数估计

### 6.1 参与方程（种不种大豆）

```
plant_soy_it = 1{ α + β_π·Δπ̂_it + γ1·plant_soy_{i,t−1} + γ2·Peer_{v,t−1}
                  + θ′X_it + county_c + τ_t + μ_i + ε_it > 0 },  ε ~ Logistic
```

- **主估计**：Mundlak–CRE 动态 logit（`μ_i ≈ ρ′X̄_i + a_i`，`a_i ~ N(0, σ_a²)`），并按 Wooldridge (2005) 处理初始条件问题（把初始期 `plant_soy_{i,0}` 与 `X̄_i` 一并放入）——保留截距和个体异质分布，便于 ABM 直接复用；
- **稳健**：FE 条件 logit（survival::clogit，牺牲截距但控净个体效应）、LPM（fixest::feols）；标准误一律**村级聚类**；
- X：户主年龄/教育、劳动力数、外出务工、经营规模 log(B)、生产性固定资产、保险参与、互联网使用、转入面积。

### 6.2 关键分解检验（论文结果之一）

用 `β_m·Δm̂ + β_s·Δŝ` 替换 `β_π·Δπ̂`，Wald 检验 `H0: β_m = β_s`。若拒绝且 β_s > β_m → 存在"补贴显著性"效应（每元补贴的行为撬动大于每元市场收益）；ABM 采用双系数版本，政策模拟结论会系统不同——这一检验本身即是卖点。

### 6.3 份额方程（种多少）

`E[s_it | s_it > 0, ·] = Λ(κ + φ·Δπ̂_it + γ′(同上解释变量))`，fractional logit（Papke–Wooldridge 式 quasi-binomial GLM + CRE 均值项）。
备选/稳健：三分类 MNL {纯玉米, 兼种, 纯大豆}。

### 6.4 异质性

`Δπ̂ ×`（经营规模三分组、户主年龄组、兼业与否、县）交互，或直接分组估计。ABM 中据此定义 agent 类型 g（每类各自一套系数或交互修正项）。

### 6.5 识别与解释边界（如实写入报告与论文）

- 补贴差的 **县×年×作物政策变异**（省定标准、与单户不可观测冲击弱相关）是主要识别来源；
- 价格用县级滞后中位数，缓解个体层面的联立与 division bias；
- Peer 变量用滞后值 + 县固定效应缓解反射问题（reflection），但**不宣称严格因果**；在 ABM 中作为机制通道，敏感性中可关闭；
- 年份效应 τ_t：估计时保留；导入 ABM 时不外推 τ，将其样本方差并入宏观随机冲击 σ_macro（§7.5）——此处理必须在技术附录写明。

### 6.6 参数交付

`output/params/behavior_params.json`：参与/份额方程全部系数、VCV、σ_a、残差方差、δ_rot、δ_rep、λ_e 占位、冲击方差（Phase 5 回填）。

**DoD**：表 2（参与方程三列 + 份额方程一列 + 分解检验一列）；phase3_report 报告平均边际效应，口径统一为"**补贴差每 +100 元/亩 → P(种大豆) 变动 x.x 个百分点**"。

## 7. Phase 4 ABM 构建

### 7.1 设计概览（ODD 简版；完整 ODD 见 Phase 7 附录）

| 要素 | 设定 |
|------|------|
| Purpose | 模拟补贴/价格情景下农户玉豆种植概率与份额的分布动态与财政成本 |
| Entities | 农户 agent（≈992，2024 年截面初始化）、村（peer 容器）、县（价格/补贴单元）、政策环境 |
| Scales | 年步长；模拟期 2025–2030 |
| Stochasticity | 价格冲击、单产冲击、宏观年冲击、决策抽签、份额残差 |
| Initialization | 2024 年实际状态（s、特征），记忆用 2021–2024 数据初始化 |
| Input | 情景文件（补贴/价格路径） |

### 7.2 Agent 状态

`{id, county, village, 类型 g, B_i（玉豆用地，固定）, X_i（特征；年龄每年 +1，其余准固定）, s_{t−1}, 记忆(p̂_corn, p̂_soy, ȳ), a_i ~ N(0, σ̂_a²) 一次性抽取, 份额残差经验分布}`

### 7.3 年度时序（每个 t，顺序执行）

1. **政策公布**：读取情景 `{s_soy, s_corn, s_rot}_t`；
2. **预期形成**：p̂ 自适应更新；`ŷ_corn = ȳ_corn,i·(1 + δ_rot·s_{t−1})`，`ŷ_soy = ȳ_soy,i·(1 − δ_rep·s_{t−1})`；
3. **计算 Δπ̂_i**：轮作补贴预期项以 `s_rot · min(E[s_t], 1−s_{t−1})` 近似并入大豆侧（近似方法写入附录）；
4. **决策**：`P_i = Λ(线性指标 + a_i + ε_macro,t)`；抽 U(0,1) 定 plant_soy；若种，`s_i = clip(份额方程拟合均值 + 残差抽样, (0,1])`；不种则 s_i = 0；
5. **实现**：价格 `P_t = p̂·exp(ε_p,county)`；单产 = 预期 × exp(ε_y,county + ε_y,i)；结算农户收入与财政支出；
6. **更新**：`Peer_{v,t}`（村内实际份额，leave-one-out）、价格记忆、`s_{t−1} ← s_t`；
7. **记录**：户级 {plant_soy, plant_corn, plant_both, s, 收入}；聚合 {大豆面积份额, 财政成本}。

### 7.4 财政成本核算

```
Cost_t = Σ_i B_i·[ s_i·s_soy,t + (1−s_i)·s_corn,t + min(s_i, 1−s_{i,t−1})·s_rot,t ]
```

### 7.5 冲击结构校准来源

- σ_p：县级实际价格相对预期的残差 SD（分作物）；
- σ_y：T2.3 单产方程残差，分解为县共同 + 户个体两层；
- σ_macro：τ_t 的样本 SD（§6.5）。

### 7.6 市场闭合

- **基线：价格外生**——三县样本供给不影响全国玉豆市场，这是诚实且可辩护的设定；
- 扩展（附录敏感性）：`p_t = p̄·(Q_t/Q̄)^(−1/η)`，η 取文献需求弹性，仅演示价格反馈方向，不作主结果。

### 7.7 实现规范

- R 向量化（agent × MC 存 data.table 长表或三维数组），**不写逐 agent 显式循环**（只循环年份）；
- MC = 500 次（≈992 agents × 6 年 × 500 次，运算量为秒级）；
- 模块：`abm_init() / abm_expectations() / abm_decide() / abm_realize() / abm_step() / run_scenario(scn)`，参数一律从 `behavior_params.json` 读取；
- 单元测试：s ∈ [0,1]、面积守恒、无 NA 泄漏、同 seed 完全复现；
- 冒烟测试：S0 空转 6 年，无政策变化时聚合份额不应系统性漂移。

**DoD**：模块代码 + 单测通过 + 冒烟测试报告 + 一次基线整跑输出。

## 8. Phase 5 校准与验证

- **T5.1 矩匹配校准**：待校准 {λ_e, 冲击缩放系数}；目标矩（2021–2023 实际）：大豆参与率均值、s 均值、进入率 P(0→+)、退出率 P(+→0)。网格搜索最小化加权矩距离。
- **T5.2 事件验证（本研究的核心可信度证据）**：以 2021 年状态初始化，输入 2022 年实际价格与补贴（采用"强政策信号"预期设定），检验模拟的 2022 年大豆参与率/份额**跳升方向与幅度** vs 实际（全样本 + 连续户子样本各一遍，规避 2023 扩容干扰）。初始验收线：方向正确，幅度落在实际变化的 ±50% 区间（可与用户商调松紧）。
- **T5.3 留出验证**：仅用 2019/2021–2023 数据重估参数 → 模拟 2024 → 对比：个体层 AUC ≥ 0.75；聚合大豆份额误差 ≤ 5 个百分点。
- **T5.4 外部一致性（可选）**：模拟县级份额 vs 统计年鉴县级玉豆播种面积份额。
- **T5.5 敏感性套餐**：参数从 VCV 抽样（给出参数不确定性带）；λ_e ∈ {0.5, 0.8, 1}；δ_rot/δ_rep 开关与文献区间；Peer 开关；补贴预期三种时点设定。
- 未达验收线的处置：回到 Phase 2/3 检查设定（**优先检查补贴预期时点与价格构造**），迭代过程完整记录于 phase5_report，不得静默修改。

**DoD**：表 3 验证指标汇总；模拟 vs 实际拟合对比图；校准后参数写回 `behavior_params.json`。

## 11. 风险与备选方案

- **A 跨年列名对齐失败** → 主面板收缩为 2021–2024，2019–2020 仅作描述；
- **B 地块模块可用且可跨年追踪** → 决策层升级为"地块×年"（轮作直接观测、δ 估计更准），估计改为地块选择条件 logit，ABM agent 内嵌地块列表——Phase 0 结论出来后与用户商定；
- **C 单位价值噪声过大**（县×年中位数变异系数异常）→ 改用官方县/省价格序列；
- **D 2022 扩种信号在样本中偏弱**（样本更替干扰）→ 用连续户平衡子样本 + 县级聚合做事件验证；
- **E 外推与代表性**：三县非全省概率抽样 → 正文结论限定为"样本县农户"，借三县积温带差异讨论可推广性；稳健性提供按全省县级玉豆面积再加权的聚合结果；
- **F 2023 扩容新户** → 主估计用连续 ≥3 年户，全样本作稳健性；
- **G 风险偏好通道无法识别** → S4 保险情景降级为附录讨论，不进主文。
