# Nature 子刊故事线设计（目标：Nature Food）

## 一句话故事

**中国的膳食转型不是一个国内营养政策问题，而是一次全球规模的资源与环境再配置**：
14亿人吃什么，决定了巴西的大豆田、新西兰的牧场、全球的碳/水/氮预算——而"温和转型"
(MTS)能以约六成的调整成本锁定健康与全球环境红利的大部分。

## 为什么现在的版本只能投 field journal

原稿（Food Policy水平）：中国单国模型 + 单一碳指标 + 中国碳系数库 + 表格式呈现。
故事是"中国膳食转型影响中国的需求、营养、排放"——重要但不新（Springmann、He Pan
等已做过类似维度）。

## 升级后的三层新颖性

1. **全球溢出（新的核心）**：首次用"中国农业部门模型+世界多区域市场模型"的联合框架
   量化中国膳食情景的世界市场传导。关键数字（2050，HDS相对BS）：
   - 世界猪肉价格 −56%、大豆 −35%、玉米 −33%；唯独奶粉价格 +20%（逆势）
   - 巴西大豆产量 −11.7%、阿根廷 −14%；美国猪肉 −46%；澳新奶业重构
   - 中国以外世界释放耕地 21.7 Mha（≈一个英国的耕地面积）——供给侧碳/生物多样性
     红利发生在境外，这是"telecoupling"叙事
2. **多维环境足迹 + 全球净效应核算**：碳（FAOSTAT farm-gate主方案 + P&N全LCA敏感性）、
   蓝水、活性氮、土地四指标；并回答审稿人质疑的贸易一致性问题——
   "中国膳食转型的**全球净减排**=中国境内减排 + 贸易伙伴生产调整的引致变化"，
   避免只算中国而把排放"泄漏"给世界的错觉。
3. **转型路径而非终点比较** + 人口结构（老龄化标准人当量）：保留原稿的方法贡献，
   但把 MTS 从"中间情景"升格为政策主角：MTS 以 PTS→HDS 距离的一半，
   实现 HDS 环境红利的 55–65%（世界价格传导、碳减排份额均如此）——
   "递减的转型成本、超比例的环境回报"。

## 与审稿意见的对应

- "贸易与排放系数不一致" → 全球净效应核算正面解决（第2层新颖性）
- "方法不透明/无引用" → 开源Python复现（GitHub repo），逐格验证报告
- "A1-C6未定义/健康基准未列表" → 情景定义csv+健康基准表进正文/SI
- "只有表格" → 全图版重构
- "加工食品未纳入" → 限于CASM商品范围，在limitations中量化讨论（糖已在模型内）
