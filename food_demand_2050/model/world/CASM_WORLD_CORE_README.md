# CASM-World Model — 中国(CASM)+ 世界(PEATSim)联合模型 Python 版

以 CASM Python 模型为基础、结合 USDA ERS **PEATSim**(Partial Equilibrium
Agricultural Trade Simulation)模型构建的全球农业局部均衡模型。
纯 Python 实现,基期 **2023**(FAO/PSD 最新完整年),投影 2024–2035。

## 设计(按用户规则)

| 组成 | 来源 |
|---|---|
| 模型结构/方程 | PEATSim(常弹性+部分调整;净贸易闭合;世界价格出清)|
| 区域 | PEATSim 的 12 区域 + ROW:美/欧盟/日/加/墨/巴西/阿根廷/**中国**/澳/新/韩/印 + 世界其他 |
| 商品 | 31 种(谷物、油籽/油/粕、糖、棉、肉、奶及乳制品、生物燃料)|
| **中国数据** | **CASM 平衡表**(0DATA.XLSX 2022/2023 列,权威来源)|
| 其他国家数据 | 世界工作簿(USDA PSD 口径 2022/2023,即 FAO 同期最新;日本在 FAO SUA 中缺失,由此补齐)|
| 行为参数(弹性) | **PEATSim params.xls**(13 区域完整弹性体系)|
| 世界价格(基期) | 2023 年实际价格(PEATSim 自带价格为旧外推,已替换)|
| 宏观(GDP/人口/汇率) | 更新版 Macrodata(至 2035;PEATSim 自带宏观仅至 2017)|
| 关税 | 更新版 TariffCuts(含 2025 现势政策)|
| FAO 数据 | SUA/QCL/FBS 批量数据已下载(`/root/data/CASM/fao_data/`),用于交叉核对 |

### 中国数据规则(用户指定)

- 中国各商品的生产、消费、贸易**一律用 CASM 数据**;
- CASM 与世界工作簿不一致时,**产量差额由 ROW 反向吸收**(世界总量不变),
  贸易差额经世界再平衡机制进入 ROW,ROW 的"其他用途"作为账户残差闭合;
- CASM 未覆盖的商品(葵籽系、乳制品细分、生物燃料、其他油)中国部分沿用世界工作簿;
- 已识别并处理的口径差异:
  - 稻谷(CASM 原粮)×0.70 → 成品粮(与 PSD 一致,数据同源验证);
  - 糖料(CASM 折糖口径 ≈8 Mt ≠ PEATSim 甘蔗原料口径 ≈105 Mt)→ 不映射;
  - 原奶(CASM 乳品进口按原奶当量记录,PEATSim 中原奶不可贸易且消费走
    加工闭合;两边产量本就同源一致 41.97 Mt)→ 不映射;
  - CASM 的种子/损耗/加工需求归入"其他用途"。

## 运行

```bash
python3 run_baseline.py     # 基准 2024–2035(约 1 分钟),输出 CSV + 基准检查
python3 -m cw.data          # 数据层:世界平衡与中国覆盖检查
```
依赖:`numpy`。无需 GAMS/xlrd(自带纯 Python 旧版 .xls 读取器)。

输出(`output/`):
- `casm_world_results_long.csv` — 长表(商品/区域/年/变量/值)
- `casm_world_benchmark.txt` — 2023 基准复现检查

## 验证

- **2023 基准复现**:产量/消费/面积/进出口/世界出清全部 ~1e-13(机器精度);
- **世界贸易平衡**:ROW 再平衡后 7e-15;
- **递归投影**:2024–2035 全部收敛(世界出清 ~1e-13,每年 3–4 次牛顿迭代);
- **中国轨迹(CASM 口径)**:大豆进口 98→106 Mt,玉米进口 27→37 Mt,
  小麦进口 12→21 Mt,猪肉产量 58→70 Mt(2023→2035)。

## 模块

| 文件 | 内容 |
|---|---|
| `cw/gdxxrw.py` + `cw/xls_reader.py` | Excel/BIFF8 数据读取(纯 Python)|
| `cw/data.py` | 13 区域 RAWDATA 组装、**CASM 中国覆盖 + ROW 吸收**、账户闭合 |
| `cw/calib.py` | 价格块、PEATSim 弹性(部分调整缩放)、贸易分区、截距校准 |
| `cw/model.py` | 化简 MCP:世界价格 PRF ⊥ 全球出口=进口;牛顿求解 |
| `cw/simulate.py` | 2024–2035 递归动态 |

求解方法与 SILK 移植版相同:全局未知量只有各贸易商品的世界价格(~26 个),
给定世界价格,各区域价格块、供需、净贸易全部前向推出,世界出清条件反解价格。
