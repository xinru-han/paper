# 食物需求预测 2050 —— 模拟方案（Scenarios）

本目录由原始工作簿 `需求预测20251119 - CASM人均.xlsx`（23 个 sheet）整理而成。
所有 CSV 为 UTF-8（带 BOM），列名为英文，数值直接取自工作簿对应 sheet，未做四舍五入以外的加工。

## 情景体系

三条膳食路径 × 六种人口/城镇化组合 + 1 个基准情景 = 19 个情景。

**膳食路径**

| 路径 | 含义 |
|---|---|
| **BS** 基准 | 固定 2023 年收入弹性外推（sheet13 平滑弹性路径），中人口、中城镇化 |
| **PTS**（A 组） | 弹性法：收入弹性随人均 GDP 按 Gouel & Guimbard (2018) 跨国规律动态插值（sheet04→sheet05） |
| **HDS**（B 组） | 膳食指南法：2050 年人均消费收敛到六套膳食标准的综合基准（sheet11） |
| **MTS**（C 组） | 中间路径：逐年增长率 = PTS 与 HDS 对应增长率的算术平均 |

**人口/城镇化维度（X1–X6，套用到 A/B/C 各组）**

| 编号 | 定义 |
|---|---|
| X1 | 中人口（DRC）+ 中城镇化 |
| X2 | 高人口（UN WPP 高方案：2035 年 14.20 亿 / 2050 年 13.89 亿） |
| X3 | 低人口（UN WPP 低方案：2035 年 13.45 亿 / 2050 年 12.00 亿） |
| X4 | 高城镇化 |
| X5 | 低城镇化 |
| X6 | 老龄化：成人当量人口 + 老龄化弹性调整（弹性 −0.0314） |

完整 19 行定义见 `scenario_definitions.csv`。

## 方法与公式

**1. 弹性法（BS / PTS）**

人均消费量按收入弹性递推：

```
q(t+1) = q(t) × (1 + ε(t) × gy(t))
```

其中 `gy(t)` 为人均 GDP 增长率；BS 用固定基年弹性（sheet13），PTS 的 `ε(t)` 随当年人均 GDP 在 `income_elasticities.csv` 的档位（13693→50000 美元）间线性插值（sheet04→sheet05）。

**2. 膳食指南法（HDS）**

- 六套标准（中国指南 2022、EAT-Lancet、中国台湾、日本、地中海、综合）统一折算为 g/人/天摄入量；
- 综合基准 = 五套标准"中间值"的最小值/最大值/中点（`composite_*` 列）；
- 摄入量 ÷ 可食比例 × 365 ⁄ 1000 → 年人均购买量 kg（`purchase_*` 列）；
- 由 2023 年 CASM 实际人均消费到 2050 年达标值求隐含年均增长率 `r`：
  `r = (target/actual_2023)^(1/27) − 1`，人均路径按 `q(t) = q(2023)×(1+r)^(t−2023)` 收敛（sheet11）。

**3. MTS 平均法（C 组）**

逐年增长率取两条路径的算术平均：

```
g_MTS(c,t) = [ g_PTS(c,t) + g_HDS(c,t) ] / 2
```

`per_capita_paths.csv` 未含 MTS 行，可由 BS/PTS/HDS 路径按上式后续计算生成。注意商品口径映射：谷物 = 稻谷+小麦+其他粮食，肉类 = 猪+牛+羊+鸡。

**4. 成人当量法（X6 / A6、B6、C6）**

按年龄-性别能量需要将人口折算为成人当量（sheet19–21 系数，sheet22 总量）：成人当量人口 14.0967（2023）→ 13.9697（2035）→ 12.6967（2050）亿；同时在弹性中加入老龄化项（老龄化率每上升 1 个百分点，弹性调整 −0.0314，sheet07）。

**5. 总量**

```
Q(scenario, c, t) = q(pathway, c, t) × POP(variant, t)
```

肉类总量再按 `meat_structure_shares.csv` 的份额分解到猪/牛/羊/鸡（PTS 用 sheet09"调整后"份额，HDS 用 sheet11 份额）。

## 关键宏观假设

- 人口（亿）：中方案 DRC 14.0967（2023）→ 13.6732（2035）→ 12.5859（2050）；高/低为 UN WPP 2024。
- 人均 GDP（固定价格美元）：13693（2023）→ 23548（2035）→ 41121（2050）（sheet09；sheet05 另有一条 12681 起点的序列，见下文"口径差异"）。
- 城镇化（中方案）：仅 2035 年 75.4% 与 2050 年 81.4% 两个锚点，`macro_assumptions.csv` 中 2036–2049 为两点线性插值，2035 年前留空。
- 基期：2023 年 CASM 校准人均消费量（sheet03，最终采用）。

## 数据来源

- 收入/价格弹性跨国规律：Gouel, C. & Guimbard, H. (2018)（sheet00、sheet04）。
- 膳食标准：中国营养学会《中国居民膳食指南（2022）》；EAT-Lancet（eatforum.org）；台湾国民健康署；日本厚生劳动省/农林水产省；地中海膳食（Queensland Health）。韩国标准原表仅有"份数"未折算克重，未纳入综合基准。
- 人口：中方案 DRC 专家预测；高/低方案 UN World Population Prospects 2024。
- 基期消费：CASM 模型 2023 年校准值；对照 2021 年统计局住户调查（户内）。
- 营养成分与可食比例：sheet12（21 个 CASM 商品）。

## 已知口径差异 / 数据说明

整理中发现以下不一致，使用时须注意：

1. **人均 GDP 两条序列**：sheet05/07/13 用 12681 美元（2023）起点的序列递推弹性；sheet04 弹性档位与 sheet09 用 13693 美元（固定价格）序列。`macro_assumptions.csv` 主列取 13693 序列，12681 序列存于 `gdp_per_capita_usd_alt`。
2. **稻谷/小麦弹性跳变**：sheet05（PTS）中稻谷、小麦弹性在 2032 年从约 −0.057 跳到 −0.25（人均 GDP 跨过 2 万美元时切换到 Gouel&Guimbard 谷物档位），sheet13（BS）为平滑序列无跳变；sheet07（老龄化）则从 2023 年起即为 −0.25。
3. **奶类基期不一致**：sheet05/07/11 奶类 2023 年人均 37.05 kg，sheet13（BS）为 19.531 kg（口径疑为户内购买量），导致 BS 与 PTS 的奶类路径不可直接比较。
4. **鸡肉基期不一致**：sheet09 调整后基期鸡肉 13.58 kg/人（份额 0.244），sheet05/11 为 17.19 kg/人（HDS 份额 0.289），两套肉类份额基期不同源。
5. **人口旧序列**：sheet00 的人口路径（2050 年 12.938 亿）与最终采用的 sheet09 DRC 序列（12.5859 亿）不一致，前者为早期版本，未采用。
6. **HDS 商品口径**：sheet11 的 14 商品分解路径含"薯类"（TUBR）而无"其他粮食"、"豆类"单列，与 PTS 的 14 商品（含 OTGR）不完全对应；HDS 11 食物组中的豆类、薯类在与 PTS 拼接时需单独处理。
7. **综合基准的构造**：综合值并非五套标准的算术平均，而是五套标准"中间值"的跨标准最小值/最大值及其中点。
