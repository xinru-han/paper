# 修改说明 / List of corrections

复刻投稿稿的数据与代码后所做的更正与数字更新。分类框架（MCI/AMS/AML ×
单产/面积/效率）、方法框架与主要结论均保持不变；Table 1（基准综合效应）由更新后

## 一、必须修正的错误（Errors fixed）

1. **删除使用虚构数据的代码模块。** 原分析脚本 `3-meta-regress.py` 中的
   "高斯过程回归（GPR）代理模型" 与部分 "XGBoost+SHAP" 模块使用了硬编码的
   手写数组（非由文献提取数据生成），与正文无关。按要求，投稿代码不再包含、
   也不计算这些模块。

2. **Meta 回归缺失方法学控制变量。** 原代码的 WLS Meta 回归未纳入 log(N)，
   与正文 Table 3 含 log(N) 行不一致。已在 `meta_analysis.py` 中补齐
   （面积维度因样本量小按原文去掉 log(N)）。

3. **Table 6 弹性与 Table 7 冲击参数内部不一致。** 原稿 S1 单产 Shifter
   0.434%/年 ÷ 增速 2.4%/年 = 隐含弹性 0.181，但 Table 6 报告中位数 0.171
   （S2 同样不一致）。已按式(25) 用同一套（可复现的）弹性中位数统一重算
   Shifter，消除该不一致。

4. **样本量修正。** 采用作者复核后的样本量（22 项研究更新），用于 log(N)
   与样本量加权稳健性。
