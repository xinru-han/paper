# 多效应量提取协议（v3扩充版）

参照 IFPRI DP 02361（Roche等2025，215篇/13000+条，两层随机截距）与
Tan等(2026, JAE)（34篇/87条，逆方差加权+WLS）的做法，放弃v2"一文一主效应量"
原则，改为**一篇文献提取全部合格效应量**，效应量在文献内嵌套，用多层模型+
文献层面聚类稳健SE处理依赖。

## 合格效应量定义

来自机械化相关自变量对以下因变量的回归系数（正文主表+分作物/分区域/
分规模/稳健性表均可，剔除中介/交互项列）：
- **Yield**：粮食/水稻/小麦/玉米等单产、总产（log或level）
- **Area**：粮食播种面积、种粮面积占比、趋粮化/种植结构（粮作比例）
- **Efficiency**：技术效率TE、全要素生产率、成本效率、环境效率

机械化自变量分三路径：
- MCI 农机资本投入：机械投入费/额、农机总动力、农机使用(强度)、购置补贴
- AMS 农机社会化服务：农机服务/外包/托管/机耕/跨区作业、服务费用、服务比例
- AML 综合机械化水平：耕种收综合机械化率、机械化水平指数、农机-劳动耦合

非机械化自变量（地块特征、户主特征、金融、政策总量等）不提取。

## 每条效应量记录字段

study_id(文件名), 编号(对应P_/E_，如可匹配), author_year, lang(cn/en),
Target, Path, crop, dep_var(原文因变量及形式), x_var(原文自变量及形式),
beta, se, t_stat, p_report(星号或p值), N, df, model(FE/SFA/IV/Tobit/SDM等),
endog(0/1), micro(0/1), region, data_years, spec_type(baseline/subgroup/robust),
mean_y, mean_x(换算弹性用，如报告), table_source(第几表)

## 效应量标准化

- PCC = t/√(t²+df)，SE_PCC = √((1-PCC²)/df)；df缺失用N-k，再缺失用N。
- 弹性：log-log直接取β；dummy/半对数取半弹性并标注；level模型有均值时换算。
- 只录入原文明确报告的数字；任何字段拿不准记NA，不推断、不外推。

## 质量控制

- 极端值按IFPRI规则 [Q1−3×IQR, Q3+3×IQR] 在分析阶段处理（不在提取阶段删）；
- 每条记录 table_source 可回溯核对；
- 与v2 check版56条主效应量交叉核对作者/样本量。
