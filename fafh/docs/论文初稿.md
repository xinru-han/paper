# 基于机器学习的中国居民户外食物消费系数预测研究

## 摘要

**背景**：准确预测居民户外食物消费系数对于理解食物消费结构变化、评估食物安全政策效果具有重要意义。然而，现有研究多基于微观调查数据，难以直接应用于宏观层面的预测。

**目的**：本研究旨在构建一个综合的机器学习框架，预测中国各省份不同食物品类的户外消费系数，为政策制定提供科学依据。

**方法**：采用12种机器学习模型（包括传统机器学习模型和深度学习方法），结合Copula收入分布匹配、Kriging空间插值、Bootstrap预测区间等方法，对15个食物品类（粮食四类、蔬菜、肉类、水产品等）的户外消费系数进行预测。研究使用微观调查数据训练模型，通过收入分布匹配将模型应用于宏观预测场景。

## 1. 引言

### 1.1 研究背景

随着中国经济的快速发展和居民生活水平的提高，食物消费模式发生了显著变化。户外消费（即在外就餐）已成为居民食物消费的重要组成部分，对理解食物消费结构、评估食物安全政策效果具有重要意义。

户外消费系数（户内外消费量/户内消费量）是衡量户外消费水平的关键指标。准确预测各省份不同食物品类的户外消费系数，有助于：
- 理解食物消费结构的地域差异和时间变化趋势
- 评估食物安全政策对不同地区的影响
- 为食物供需平衡分析提供数据支持

### 1.2 研究问题与挑战

现有研究面临以下挑战：

1. **数据不匹配问题**：微观调查数据包含个人收入（indinc）等特征，而宏观预测数据只有平均收入（income），缺乏个人收入分布信息。

2. **空间异质性**：不同省份的食物消费模式存在显著差异，需要处理空间相关性。

3. **数据缺失**：部分省份和年份的消费数据缺失，需要有效的插值方法。

4. **模型选择**：不同机器学习模型在不同品类上的表现存在差异，需要系统比较和选择。

5. **预测不确定性**：需要量化预测的不确定性，提供预测区间而非仅点估计。

### 1.3 研究目标

本研究旨在：
1. 构建一个综合的机器学习框架，预测中国各省份15个食物品类的户外消费系数
2. 比较12种机器学习模型的预测性能
3. 评估模型的稳健性和预测不确定性
4. 为政策制定提供科学依据

### 1.4 研究创新点

1. **Copula收入分布匹配**：解决微观-宏观数据不匹配问题，将微观数据的收入分布匹配到宏观预测场景
2. **多模型集成比较**：系统比较12种机器学习模型，包括传统方法和深度学习方法
3. **空间插值融合**：结合Kriging空间插值和产量占比信息，提高缺失省份的预测精度
4. **Bootstrap预测区间**：提供预测的不确定性量化
5. **稳健性检验**：通过不补缺失样本的预测，评估模型对数据缺失的稳健性

### 2.2 预测目标

**户内消费系数（ratio）**：户内消费量 / 户内外消费量，取值在 (0, 1]

**户外消费系数（coef）**：户内外消费量 / 户内消费量 = 1 / ratio

**预测品类**（共15个）：
- **粮食四类**：稻谷（q_daogu）、小麦（q_xiaomai）、豆类（q_doulei）、杂粮（q_zaliang）
- **蔬菜**：q_shucai
- **肉类**：猪肉（q_zhurou）、牛肉（q_niurou）、羊肉（q_yangrou）、禽肉（q_qinlei）
- **其他**：水产品（q_shuichanpin）、蛋类（q_danlei）、奶类（q_nailei）、水果（q_guaguo）、食用油（q_youliao）、糖（q_tang）

### 2.3 模型选择

本研究比较了12种机器学习模型：

**传统机器学习模型**：
1. **LightGBM**：梯度提升决策树，高效且准确
2. **XGBoost**：极端梯度提升
3. **CatBoost**：类别特征友好的梯度提升
4. **Random Forest**：随机森林
5. **Lasso**：L1正则化线性回归
6. **Ridge（Linear）**：L2正则化线性回归

**深度学习方法**：
7. **MLP**：多层感知机
8. **TabNet**：基于注意力机制的表格数据深度学习
9. **TabM**：参数高效的集成MLP（参考 yandex-research/tabm）
10. **TabPFN**：基于Transformer的先验拟合网络
11. **ResNet（Tabular）**：残差网络应用于表格数据
12. **FT-Transformer**：特征标记Transformer

### 2.4 关键技术方法

#### 2.4.1 Copula收入分布匹配

**问题**：训练数据（微观）包含个人收入（indinc），而预测数据（宏观）只有平均收入（income），缺乏个人收入分布。

**方法**：使用Copula方法将微观数据的收入分布匹配到宏观预测场景：
- 保持微观数据的收入分布形状
- 缩放均值以匹配宏观平均收入
- 为宏观数据生成匹配的个人收入值（indinc）

**实现**：在 `data_preparation_advanced.py` 的 `load_and_prepare_data_advanced()` 中，通过 `match_income_copula()` 函数实现。

#### 2.4.2 Kriging空间插值

**问题**：部分省份在微观数据中缺失，需要预测这些省份的户外消费系数。

**方法**：使用Kriging空间插值方法：
- 基于已知省份的预测值
- 考虑省份间的空间距离
- 结合各省产量占比信息进行融合

**实现**：在 `apply_kriging_interpolation()` 函数中实现，使用IDW（反距离加权）方法。

#### 2.4.3 Bootstrap预测区间

**方法**：通过多次不同随机种子的预测，量化预测不确定性：
- 运行N次（默认30次）预测，每次使用不同随机种子
- 计算预测值的均值、2.5%分位数、97.5%分位数
- 提供预测区间而非仅点估计

**实现**：通过 `run_bootstrap.py` 脚本实现。

#### 2.4.4 早停机制

**方法**：在模型训练过程中监控验证集损失，当验证损失不再下降时提前停止训练，防止过拟合。

**实现**：各模型均实现早停机制（如MLP的 `early_stopping=True`，TabNet的 `patience` 参数等）。

#### 2.4.5 超参数优化

**方法**：
- **固定超参数**：大部分模型使用固定超参数（基于经验或初步调参）
- **Optuna优化**：FT-Transformer使用Optuna进行50次超参数搜索（TPE采样器）

#### 2.4.6 交叉验证

**方法**：
- **补缺失阶段**：5折交叉验证评估各模型补缺失精度
- **模型训练**：部分模型使用TimeSeriesSplit进行时间序列交叉验证

## 4. 方法

### 4.1 模型训练

#### 4.1.1 训练数据

- **输入特征（X）**：包含个人收入、宏观特征、产量特征、省份和年份
- **目标变量（y）**：户内消费系数（ratio），取值在 (0, 1]
- **数据来源**：微观调查数据（`data.csv`）

#### 4.1.2 训练策略

**统一随机种子**：所有模型使用随机种子42（可通过环境变量 `PREDICT_SEED` 修改）

**早停机制**：监控验证集损失，防止过拟合

**超参数设置**：
- 大部分模型使用固定超参数（基于经验）
- FT-Transformer使用Optuna进行50次超参数搜索

#### 4.1.3 模型实现细节

**LightGBM**：
- `n_estimators=100`, `max_depth=6`, `learning_rate=0.1`
- `verbosity=-1`（抑制输出）

**XGBoost**：
- `objective='reg:squarederror'`, `max_depth=6`, `learning_rate=0.1`
- `n_estimators=100`

**CatBoost**：
- `iterations=100`, `depth=6`, `learning_rate=0.1`
- `verbose=False`

**Random Forest**：
- `n_estimators=100`, `max_depth=10`
- `random_state=SEED`

**Lasso**：
- `alpha=0.01`

**Ridge（Linear）**：
- `alpha=1.0`

**MLP**：
- `hidden_layer_sizes=(64, 32)`, `max_iter=500`
- `early_stopping=True`

**TabNet**：
- `n_d=64`, `n_a=64`, `n_steps=5`, `gamma=1.5`
- `max_epochs=100`, `patience=10`

**TabM**：
- 使用官方 `tabm` 包（yandex-research/tabm）
- `k=32`（集成大小），`d_token=64`，`n_layers=3`
- 小批量训练（batch_size=512）以控制GPU显存

**TabPFN**：
- 使用本地checkpoint：`tabpfn-v2.5-regressor-v2.5_default.ckpt`
- 不可用时退化为MLP

**ResNet（Tabular）**：
- 残差块结构，适用于表格数据

**FT-Transformer**：
- Optuna 50 trials超参数优化
- `d_token`, `n_layers`, `n_heads`, `dropout`等通过TPE采样器优化

### 4.2 预测流程

#### 4.2.1 粮食结构预测

**目标**：预测稻谷、小麦、豆类、杂粮四类在粮食消费中的占比

**方法**：
1. 从微观数据计算：稻谷 = total_大米/0.7，计算四类占比
2. 对四类占比分别建模预测
3. 缺失省份：使用空间插值（IDW）+ 产量占比融合

**输出**：`grain_structure_predictions_<model>.csv`

#### 4.2.2 户外消费系数预测

**主流程（补缺失）**：
1. 若存在 `data/imputed_ratios_best.csv`，使用统一补缺失样本
2. 训练模型预测户内消费系数（ratio）
3. 转换为户外消费系数：coef = 1 / ratio
4. 缺失省份：使用Kriging空间插值

**稳健性检验（不补缺失）**：
1. 仅使用有观测值的样本训练
2. 评估模型对数据缺失的稳健性

**输出**：
- `predictions_<model>.csv`（主流程）
- `predictions_<model>_robust.csv`（稳健性）

#### 4.2.3 Bootstrap预测区间

**方法**：
1. 运行N次（默认30次）预测，每次使用不同随机种子（42, 43, ..., 42+N-1）
2. 计算预测值的均值、2.5%分位数、97.5%分位数
3. 提供预测区间

**输出**：`predictions_<model>_bootstrap.csv`

### 4.3 后处理

#### 4.3.1 省级户内外消费量计算

**粮食四类**：
- 省户内人均 = `q_liangshi` × 占比
- 省户内外人均 = 省户内人均 × 户外消费系数

**非粮食类**：
- 省户内人均 = `data_q.csv` 对应值
- 省户内外人均 = 省户内人均 × 户外消费系数

**输出**：`results_province_<model>.csv`

#### 4.3.2 全国户内外消费量计算

**方法**：
- 全国户外消费系数：各省系数按人口加权
- 全国户内外消费量：各省人均按人口加权平均

**输出**：`results_national_<model>.csv`

### 4.4 模型评估

#### 4.4.1 补缺失模型选择

**方法**：5折交叉验证评估各模型补缺失精度

**指标**：MAE、RMSE、R²

**输出**：
- `data/imputation_selection_results.csv`：各模型汇总指标
- `data/imputation_evaluation_detail.csv`：各模型×品类明细
- `data/best_imputation_model.txt`：选中的最优模型

#### 4.4.2 模型比较

**方法**：汇总各模型的全国预测结果

**输出**：`model_comparison_national.csv`
