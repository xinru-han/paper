## ✅ 关键区别

| 项目 | Copula阶段 | Processing阶段 |
|------|-----------|---------------|
| **位置** | `match_income_copula()` | `predict_category()` |
| **输出** | "使用Copula方法进行收入分布匹配..." | " >> Processing q_shiyongyou..." |
| **作用** | 数据准备（收入匹配） | 预测（消费系数） |
| **执行次数** | 1次（一次性） | N次（每个类别一次） |
| **处理内容** | 收入数据 | 具体类别 |
| **时机** | 预测之前 | 预测阶段 |

## 💡 简单理解

```
"使用Copula方法进行收入分布匹配..."
  = 数据准备阶段
  = "我正在为宏观数据生成个人收入值"
  = 只做一次，与类别无关

" >> Processing q_shiyongyou..."
  = 预测阶段
  = "我正在预测食用油的户外消费系数"
  = 对每个类别都执行一次
```

## 🎯 总结

**"使用Copula方法进行收入分布匹配..."** 和 **" >> Processing q_shiyongyou..."** 是**两个完全不同的阶段**：

1. **Copula阶段**：数据准备，匹配收入分布（一次性）
2. **Processing阶段**：预测阶段，处理具体类别（循环执行）

Copula方法在预测之前就已经完成了，Processing阶段使用的是Copula已经准备好的数据。

---

**记忆要点**：
- Copula = 数据准备（收入匹配）
- Processing = 预测阶段（类别预测）
- 两者是顺序关系，不是并行关系
